# Full-path folder-tab labels — 2026-10-30

Independent adaptation of [Krusader fullpath tab names](https://docs.kde.org/trunk_kf6/en/krusader/krusader/konfig-panel.html), repository #4 in the full 99-repository cohort. No upstream code copied. Commander exposes the setting per pointed tab rather than as a global panel configuration.

Show full folder path in a tab context menu replaces its short/custom label with a compact path. The custom title remains stored and becomes visible again when the option is disabled. Complete path text remains available in hover and accessibility; drawing uses at most 40 grapheme clusters, retaining the beginning and a larger identifying tail. Control characters become visible control pictures. Dotted directory names receive path-specific truncation rather than extension-priority filename shortening.

The metadata setter follows modal/delete tab guards, rejects invalid indexes and no-ops without revision changes. It updates the pointed panel without activation, listing reload, watcher changes, selection/filter/history changes or closed-tab history changes. SavedTab and suspended/visible panels own the flag; duplication, copying, moving, navigation, close/reopen and session restore retain it through existing lifecycle code. New tabs default to short labels. Legacy/malformed metadata defaults false without dropping an otherwise valid saved tab. Default false is omitted on save.

Four new regressions cover inactive-tab state/focus/generation/revision/title preservation and modal/bounds/no-op handling; saved metadata defaults/malformed values/roundtrip; bounded path truncation with Unicode clusters and controls; and preventing saved metadata from leaking onto a launch-overridden active path.
