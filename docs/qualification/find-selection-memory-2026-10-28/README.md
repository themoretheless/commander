# Remember / restore Find result selection — 2026-10-28

Independent adaptation of Double Commander's [Save Selection and Restore Selection internal-buffer commands](https://doublecmd.github.io/doc/en/help.html), scoped to Commander's Find results. No upstream code copied.

Remember selection stores one runtime snapshot of selected visible SearchLocation values plus the search root. Remembering another non-empty group replaces it; empty selection does not erase it. Restore selection replaces the current selection with remembered locations present in current visible results, clears the Shift anchor, and returns query focus. It leaves the keyboard cursor, pane selection, query and search results/counts independent. Hard-link paths and distinct archive member indexes remain separate.

The snapshot survives query reruns/refinement and temporary hiding within the same Find instance. Remembered rows missing from current results remain in the snapshot and can be restored explicitly after they return; incoming matches are not automatically selected. Different roots cannot apply it. A root edit while results still belong to the previous last-query root disables remembering/restoring, preventing rebinding an old result list to the new root. Closing Find discards the snapshot; saved query files do not persist it. This remembers locations, not a proof of unchanged file identity/content across searches.
