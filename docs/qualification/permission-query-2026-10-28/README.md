# Observed Unix permission search — 2026-10-28

Independent adaptation of Double Commander Unix permission attributes ([primary Find documentation](https://doublecmd.github.io/doc/en/findfiles.html), section 3.1), from the 99-repository cohort. No upstream code copied.

New perm:ur+uw-ux+ conditions test all required and forbidden Unix mode bits. The twelve labels cover owner/group/others read/write/execute, setuid, setgid and sticky. Concatenated terms and repeated predicates combine through AND, independent of text match mode/case policy. Invalid labels, missing signs, malformed Unicode and contradictions within a condition are rejected. Duplicate same-sign requirements are idempotent. Chips, explanations, expression round trips and saved JSON preserve the condition.

This is observed lexical mode metadata, not effective access, ACLs or a promise of runnable format. It applies to directories and symlinks as well as regular files. Native hard links retain separate result locations. type:regular limits it to ordinary files. ZIP uses the zip crate's Unix-mode metadata (which can derive modes from DOS attributes); TAR uses header mode. Synthetic archive directories do not invent permissions. Native non-Unix permissions are unknown, while archive mode conditions remain portable.

New optional index unix_mode observations survive serialization and are used without live restat. Old snapshots still load, but absent mode cannot prove any positive or negative requirement and counts as skipped. Rebuild populates it on Unix. Native permissions changed after indexing are intentionally not reflected until refresh. Schema version is unchanged. The compiled metadata stage now takes one observed-metadata record, preserving existing regular/symlink/executable flags and their unknown handling.

Regression coverage: every one of 4096 mode combinations for three required/forbidden masks; all twelve label bit mappings; malformed/contradictory/duplicate terms; expression and JSON round trips; all text modes across real native, serialized index, ZIP and TAR; native/TAR setuid/setgid, native sticky directories, symbolic-link own mode, hard links, and a post-index chmod proving cached observations. Legacy index missing-mode accounting is explicit. Special ZIP permission bits and ACLs are not fixture-qualified. Symbolic conjunction is implemented; upstream octal masks, OR groups and group negation remain outside this syntax.
