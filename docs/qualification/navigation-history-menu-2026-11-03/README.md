# Back/Forward folder history menus — 2026-11-03

Independent Rust adaptation of cohort #24 [Thunar history menus on Back/Forward](https://mail.xfce.org/pipermail/xfce-announce/2026-March/001665.html). Right-click either enabled navigation button to choose an earlier/later folder directly. Back lists nearest earlier entries first; Forward lists nearest later entries first. Full native paths are rendered as escaped labels with trail positions and a full tooltip, retaining repeated visits as distinct slots. The popup scrolls vertically. Ordinary button clicks, shortcuts and side-button history stepping keep their existing behavior.

Opening a menu captures the existing bounded per-tab jump trail and cursor, native owner, listing generation and workspace tab revision; it neither probes nor activates history targets. Before a choice is applied, those values must still match the live pane. Changed history/tab/owner/listing disables the frozen rows and asks to reopen, instead of retargeting them on a later frame. The core separately validates exact captured trail/cursor/index. Choosing a slot moves within the trail without pushing a new visit or truncating Forward, and uses the normal remembered-view/lazy listing loader. Choosing a repeated native path moves the history cursor without reloading the same folder. A missing target uses the listing's normal error state; this direct choice does not prune other history entries or preflight every location.
