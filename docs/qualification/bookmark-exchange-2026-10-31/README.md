# GTK/Nautilus bookmark text exchange — 2026-10-31

Independently implements the local URI/label record format used by [GTK's bookmark manager](https://raw.githubusercontent.com/GNOME/gtk/main/gtk/gtkbookmarksmanager.c), supporting the Nautilus cohort (#22). No GTK/application implementation is copied or installed.

## Workflow and boundaries

Palette **Import favorites from GTK text** opens a review window. Paste bookmark text, press **Preview bookmarks**, select/unselect ready rows and press **Add selected favorites**. Each nonblank/noncomment line contains a `file://` URI and optional space-separated label. Unicode/percent-encoded paths, spaces in labels, local `localhost` authority, CRLF and an initial UTF-8 BOM are supported. Labels are trimmed and must meet Commander's 1–256-character/no-control policy; absent labels derive from the final path component or `/`.

The supported exchange scope is local UTF-8 POSIX paths. Remote schemes/authorities are explicitly unsupported; malformed escapes, decoded non-UTF-8/NUL, parent traversal, raw URI controls/query/fragment markers and invalid labels are marked invalid. Raw `?`/`#` filename bytes must be encoded. This is a subset of URI support in GTK, not a GIO/network/provider implementation. No imported target is probed, canonicalized, mounted or created. Ready means a valid local candidate, not proof that a directory exists; old/offline paths may be retained intentionally.

Preview distinguishes Ready, Already bookmarked, Duplicate input, Unsupported remote URI and Invalid records with line numbers and reasons. Source duplicates keep the first valid occurrence; existing paths retain their current label, position and quick-jump slot. New selected paths append in input order with no slot. Commit reparses the source, refuses changed/corrupt preview bindings and rechecks current duplicates; an entry added meanwhile cannot be overwritten. The candidate store is saved through the existing guarded persistence owner before it replaces the live model. Blocked/pre-commit failure leaves the prior model; successful-but-not-durable outcomes retain existing health warnings. Zero additions do not write. After success the review is rebased with selections cleared for added/existing rows, preventing accidental repeat additions while keeping previously unchecked choices unchecked.

Palette **Copy favorites as GTK text**, or **Copy GTK bookmarks** in the window, copies the current Favorites store, not the pasted draft. It percent-encodes paths, keeps order/labels and exports no quick-jump slots: those remain Commander-only. Empty/invalid/oversized exports fail instead of returning partial text. Import and export are bounded to 64 KiB; input additionally allows at most 1000 lines. The editor accepts an overflow sentinel so a too-large paste fails the byte limit rather than silently importing a valid prefix. Its viewport is capped at 120 points and preview rows are virtualized in a 220-point scroll area. The implementation does not read a user-selected bookmark file or synchronize external GTK configuration automatically.
