# Offline GPX route preview

Independent Commander adaptation of the route-preview capability in [Strata](https://github.com/lgse/strata/blob/ede64d928ab6723c71c774948fbf07bc24616cdb/src/services/route_preview.rs). Open Preview on a GPX file to see its track/route schematic, separate segments, point/segment counts, estimated spherical distance and available recorded elevation profile. Route / Source switches between the schematic and the existing selectable/searchable/copyable XML preview. Missing elevations and segment starts remain gaps in the profile. Track segments are never joined for rendering or distance. Longitude unwrapping keeps short date-line crossings local. This is a north-up local schematic, not a cartographic map or an ellipsoidal/geodesic measurement tool.

The existing identity-fenced background text pipeline loads the complete bounded source (256 KiB); GPX parsing then runs in a separate Rust thread, with at most two active parsers, 50,000 XML nodes and 10,000 points. A per-pane cache retains Arc results and cannot show the old route while replacement content loads. Dropped owners signal cancellation; parsing checks cancellation before XML processing and between points. XML DTDs are refused. Coordinates/elevations must be finite and within documented bounds; malformed, oversized, empty and waypoint-only files show an error, with Source still available. Supported containers are GPX 1.0/1.1 namespaces and namespace-free GPX, with top-level routes or track segments. Extension payloads do not create extra tracks. No file edits, network/tile requests, external renderer or new dependency is introduced.
