# Sort matching archive content groups — 2026-11-03

Independent adaptation of cohort #81 [Czkawka/Krokiet result sorting](https://raw.githubusercontent.com/qarmin/czkawka/master/instructions/Instruction_Krokiet.md). Expanded archive content groups can be ordered by Scan order, Extra payload bytes, Member size or Copies. Numeric modes show largest first with original scan-rank ties. Extra payload bytes is size × (copies − 1), assuming one keeper; it is not compressed disk savings and does not predict the effect of protection or replica policies.

Only a cached view permutation changes. Members, original group ranks, per-group action IDs, selections, per-group member pages and report identities stay unchanged. Changing sort returns to group page one; new scan results invalidate the cached permutation while retaining the chosen sort. Reopening starts at Scan order. Full/group exports retain original scan identities and ordering. No archive content is changed.

Two Rust regressions cover all metrics, stable ties, empty/zero groups, u64-wide sizes with u128 payload keys, immutable source groups, 201-group pagination and same-count result invalidation. Nine native checkpoints appended to the separate priority scene drive all four sort controls, select the original payload group while displayed first, return to scan order, select the original empty group and deselect the original payload group after reordering again. Every receipt checks exact original indices, unchanged report groups and cached view permutation. Existing mode/history/session/TAR/ZIP regressions remain included. verify.py independently computes each numeric ordering from captured TAR metadata and checks selection identities.

Reproduce with run_checks.py, then prepare_capture.py and CUA launch separately for archive_priority_chains, archive_protection_modes, archive_tar_content_groups and archive_content_groups, then verify.py. Native sort interactions are qualified on TAR; larger native pagination, persistent sort choice and wider platform qualification remain open.
