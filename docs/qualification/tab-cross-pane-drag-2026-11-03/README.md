# Drag tabs between panes — 2026-11-03

Independent Commander extension adapting cohort #6 [Files tabs](https://files.community/docs/features/tabs) and [dual-pane workflows](https://files.community/docs/features/dual-pane). Those references describe tab dragging and pane creation; this milestone implements insertion between Commander's existing two pane tab strips, rather than claiming identical Files behavior.

Drag a folder tab before/after a tab in the opposite pane. The destination keeps its current folder and preview; moving the source's active tab selects its neighbor. Background and protected tabs retain their owned runtime panel, view/filter, history, title, selection and column settings. The last source tab cannot move; a destination at eight tabs, pending modal, stale global revision, changed native source path or invalid boundary refuses atomically. Transfer is deferred until both panes finish rendering, preventing same-frame rows from acting on a replacement owner. Same-pane reorder and edge scrolling remain available.

Native qualification exposed an existing asynchronous activation bug: retiring rows allowed a loading frame to clamp the saved cursor to the parent row. Activation now captures remembered path/scroll intent in the listing controller before retiring rows, and the subsequent refresh preserves that intent until publication. A deterministic regression failed before this fix and passed afterward. The cross-pane core matrix also drives asynchronous listing completion after an intervening cursor-validation frame (both sides, active/background source, all three insertion boundaries).

Seven final gates passed: audit, build, 3531 tests (0 failed, 3 ignored), Clippy, default check, formatting and diff. Default compilation retains its two preexisting warnings; feature Clippy is clean. Failed initial compile, pre-fix native captures and regression failure are retained separately from final evidence.

The macOS native Miller scenario retains earlier navigation, preview, resize, keyboard, ancestor/menu/current-view/group and same-pane drag checks. It then transfers a background tab before the destination's first tab, transfers the active source after its last tab, and explicitly activates the moved tab. Exact saved-tab permutations, closed-history preservation, unchanged destination owner before activation and restored source cursor/three-item selection after activation are independently verified. All 14 native checks passed with zero external native effects. Final rendered frame was inspected. Reverse-direction insertion and capacity/stale/refusal cases are unit-qualified; native overflowing-strip scrolling, window tear-off and other platforms remain open.
