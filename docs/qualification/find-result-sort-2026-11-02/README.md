# Find result ordering — 2026-11-02

Independent adaptation of [eza metadata sorting/reverse](https://github.com/eza-community/eza/blob/main/man/eza.1.md), cohort #79, to Commander's retained Find result presentation. Sort by offers Original rank (default), natural folded Name, literal native Full path, Listed size, Allocated size, Modified, Accessed, Created, Metadata changed and Hard-link count. Descending reverses the selected key. Date buckets stay primary when Group by is active; unknown observations stay last in either direction within a bucket, and ties retain original worker rank. Listed size means the retained entry length, not recursive directory size. Allocation/link counts use native regular-file observations; archive members cannot borrow container values. Creation/status dates remain native-only, while Modified/Accessed preserve existing provider observations, including existing archive-container fallbacks.
