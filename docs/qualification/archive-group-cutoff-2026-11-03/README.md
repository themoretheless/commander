# Apply archive copy selection only to old groups — 2026-11-03

Independent adaptation of cohort #85 [fclones modified-before group restriction](https://raw.githubusercontent.com/pkolaczk/fclones/main/fclones/src/config.rs). Select copies can now be restricted to groups whose every member has a known declared archive modification time strictly before a chosen instant. Newer, equal or unknown dates skip the whole group and preserve its existing selection. Empty disables the cutoff. Editing the pending cutoff preserves selection until application. Group/global actions share the same check and retain replica counts, priority order, protected patterns and atomic identity/overlap validation.

Input accepts a UTC calendar date or RFC 3339 timestamp with an explicit offset (up to 64 bytes), including fractional and pre-epoch instants. A date means midnight UTC; leap seconds are refused. Invalid input disables selection actions and is also refused by the Rust operation before selection changes. The field is runtime-only.

Rust regressions cover parsing, strict equality, fractional boundaries, all-old/mixed-new/unknown groups, previous selections in skipped groups, both action scopes, protected patterns, malformed input and stale identities even in skipped groups. The native mode scenario retains its fourteen mode and nine list checkpoints and adds twelve cutoff checkpoints: clearing protection, exact and fractional boundaries, group skipping, pending edits, invalid/recovery, disabling/reapplying and preserving already-selected skipped groups. The previous TAR/ZIP selection/export regressions remain separate. verify.py recomputes expected keeper sets independently from the captured TAR member dates and content hashes.

Reproduce using run_checks.py, then prepare_capture.py and CUA launch separately for archive_protection_modes, archive_tar_content_groups and archive_content_groups, then verify.py. This feature uses declared archive timestamps, not live filesystem age. Persistent presets and wider native platform qualification remain open.
