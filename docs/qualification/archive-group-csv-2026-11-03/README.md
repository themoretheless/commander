# CSV archive content-group reports — 2026-11-03

Independent adaptation of cohort #85 [fclones CSV group output](https://raw.githubusercontent.com/pkolaczk/fclones/main/fclones/README.md). Copy check report CSV, Copy group CSV and Copy shown groups CSV expose full scan, one original group and combined filtered/display-order scopes. Exports include every retained member across pages and do not alter selection, rules or archive files. Existing text/JSON reports retain their behavior.

UTF-8 CSV uses a fixed 23-column header, comma separators and CRLF record terminators. The first report record captures scan status/context and exported totals; each group record preserves original scan rank, hash, byte size and member count; subsequent member records preserve original entry number, size and path. Explicit group records retain empty groups; a report record distinguishes empty grouping from unrequested groups and incomplete checks. Scope is all_scan / single_group / shown_groups. Scan counts stay complete-scan metadata; totals reflect exported groups only. Extra payload assumes one keeper and is not compressed disk savings or a policy prediction.

Untrusted archive/member paths, hashes and errors are JSON string cells with explicit _json headers: parse CSV, then JSON-decode those cells for exact values. This preserves commas, quotes, CR/LF, Unicode and formula-looking names without changing identities or exposing a leading spreadsheet formula token. Plain decimal numbers are exact text on the wire; spreadsheet imports should keep large numeric columns as text. Failed-check metadata has empty unavailable counts; zero-group results have explicit zero totals. This format does not implement a fclones importer or removal plan.

CSV uses the existing bounded output writer; JSON cells and final CSV each enforce 4 MiB, and the clipboard updates only after full success. Strict UTF-8 and invalid/repeated scope checks remain shared by all formats. Two new Rust regressions parse all scopes with the CSV reader, verify beyond-page members, formula/control/Unicode names, group order, empty groups, wide totals, incomplete versus unrequested versus empty scans and unchanged input. Existing shared bounds/non-UTF-8 tests now also run CSV.

Six appended native checkpoints drive all three export scopes and a count-filtered shown export, with four real clipboard writes and unchanged original selections. verify.py independently parses CSV and compares every row/column, totals, scope, original rank/member identity and context to captured TAR fixture metadata. Previous UI totals, search, ordering, keeper, history, session and TAR/ZIP exports remain included.
