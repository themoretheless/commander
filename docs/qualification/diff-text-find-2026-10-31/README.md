# Find text in retained diff — 2026-10-31

Independent adaptation of [Double Commander's Differ text search](https://doublecmd.github.io/doc/en/shortcuts.html), cohort #3. **Find in diff** searches displayed edit-script text, including unchanged rows hidden by Compact diff. Match case, Whole words and Regex reuse Commander's bounded Unicode search-pattern compiler. Plain queries are literal, including spaces and regex punctuation. Each matching edit-script row counts once, even with multiple occurrences; replacement minus/plus rows remain separate results. Signed gutter numbers and +/- display prefixes are not searched; existing end-of-line diagnostics in the retained text are searchable.

Typing or changing options selects the first matching row; Previous match / Next match and Enter in the query cycle through rows, wrapping at the boundaries. The selected result is highlighted and scrolled into view. If hidden, its exact equal stretch is expanded before reveal. Difference buttons/Alt navigation and compact-mode changes return highlighting to the selected difference without clearing the query. Clear find removes the query/results/error. A newly opened comparison gets fresh search state.

The query is limited to 256 characters and results to the first 4096 matching rows; a visible notice says when more exist. Invalid expressions show an error and clear stale results. Matching is cached by query/options for the immutable comparison, not rescanned on unchanged repaints. Pattern complexity limits come from the shared compiler; scans use the retained, size-bounded comparison. No workers, rereads, writes or new filesystem permissions are introduced. Searches are within individual displayed rows, with no cross-line match or replacement operation. Identical/error comparisons retain their existing messages.
