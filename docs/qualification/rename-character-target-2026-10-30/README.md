# Choose character-edit scope during batch rename — 2026-10-30

Independent adaptation of [Thunar bulk-renamer name/suffix/both scope](https://docs.xfce.org/xfce/thunar/bulk-renamer/start), repository #24 in the cohort. No upstream implementation copied. This extends Commander's positional removal and insertion/overwrite; it does not claim full Thunar/plugin parity.

Character edits selects Name stem (default), Extension, or Whole name independently of the Find/Replace target. Both removal and insertion share the selection and retain their grapheme-safe semantics. Stem preserves the extension. Extension edits its raw text without the dot and skips directories; removing a nonempty extension completely removes the separator, while inserting into an empty one creates an extension. Unchanged empty raw suffixes preserve an existing trailing dot. Whole name edits the combined filename and re-splits the resulting extension; directories remain whole stems.

Order: affix removal/replacements, component range removal, component insertion/overwrite, extension/stem case, stem decoration/counter and final cleanup. Moving extension case after character edits means newly inserted suffix text follows the requested case policy. Default Stem behavior is unchanged. Rules without positional operations preserve their previous split regardless of the selected scope. CharacterTarget defaults to Stem in old JSON and is omitted when default. Presets retain the explicit selection, Reset returns to Stem and cache equality includes scope.

Six regressions cover all targets, extension creation/removal, dotfiles/trailing dots, directories and multi-extension names, combining sequences/emoji in suffixes, replacement/removal/insertion/case composition, whole-name separator deletion, invalid/duplicate results, legacy serde, preset roundtrips, cached submit rules and real extension rename payload/Undo/Redo/sibling collision refusal. The reset/load regression also exercises nondefault character scope.

Native RenameOptions retains earlier removal/insertion stages, then re-enables underscore overwrite and requires Final_.txt. It disables from-end and requires _inal.txt; selects Extension and requires Final._xt; selects Whole name and verifies both selected scope and _inal.txt; returns to Name stem and disables insertion before continuing. Final readiness requires character phase 18, insertion phase 19, range phase 12 and overall phase 97. Earlier order/exclusion/export checks remain required. UI does not submit a rename; the workspace regression verifies actual file effects.
