# XBEL Favorites exchange — 2026-11-03

Commander accepts XBEL through its existing Favorites import preview and provides “Copy favorites as XBEL” through the command palette and import dialog. Inspired by cohort #4 Krusader and #17 Dolphin; [KDE KBookmarkManager](https://api.kde.org/kbookmarkmanager.html) documents XBEL href/title and folder structure. Independent implementation using the existing roxmltree dependency and Commander persistence owner.

Nested folders flatten in document order. Existing paths retain labels and quick slots; duplicate, remote and invalid records remain visible for review. Only checked new records append, with one persistence commit. Exports escape XML and preserve current store order; Commander slots and KDE metadata are omitted. Imported paths are never probed or created.

Limits: 64 KiB source/output, 1000 XBEL bookmark records (GTK retains 1000 input lines), 8192 XML nodes, 32 element nesting levels, local absolute UTF-8 POSIX file URIs. Unnamespaced XBEL elements only. Plain DOCTYPE declarations are accepted without fetching external resources; any literal `<!ENTITY` token is conservatively refused, including inside comments. XML entity definitions and hierarchy/metadata preservation are outside scope. Malformed documents refuse the whole preview; invalid records remain reviewable. Exports refuse invalid/non-UTF-8 paths, invalid XML characters and oversized output atomically.
