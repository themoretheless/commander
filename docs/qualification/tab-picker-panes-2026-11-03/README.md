# Limit the open-tab picker to a pane — 2026-11-03

Independent Rust adaptation of cohort #3 [Double Commander cm_ShowTabsList side selection](https://doublecmd.github.io/doc/en/cmds.html). The existing Cmd+Shift+A / `#` picker now offers Both panes, Left pane and Right pane. Labels refer to physical pane groups, independent of the focused pane. Scope only changes which captured slots are searched; it does not switch focus, load folders, alter tab order or recapture the workspace. Reopening defaults to Both panes.

The matching cache binds both the exact query and pane scope. Empty queries preserve captured slot order, name-before-path ranking stays local to the chosen pane, and same-path tabs keep distinct side/index/native identity. Changing scope retires the old row list and pending Enter, resets selection to the first new result, and repaints before any new activation. Existing native path/revision validation, pin-return behavior and query limits remain in place. Scope is transient and does not change session/profile formats.

A regression switches scopes repeatedly with the same query, checks duplicate and path fallback identity, empty-query filtering, and recovery from an overlong query. Existing picker tests retain all previous behavior. Seven gates passed: audit, build, 3550 tests (zero failed, three ignored), Clippy with warnings denied, default check, formatting and diff. Default check retains two preexisting warnings. An initial native-driver compile typo is retained in initial-build.log and was corrected before the successful gate run.

Native macOS QA opens the actual picker with ten choices. Pointer clicks on Right pane and Left pane produce exactly eight and two corresponding captured slots with no retargeting. Escape compares the full pane/tab state to the before snapshot. Reopening resets to Both panes; typing the custom title and Enter still activates the left tab from right-pane focus. All prior navigation/menu/tab/pin/path receipts are retained, all fourteen framebuffer checks pass, zero external native effects occur, and the final frame was inspected. The verifier checks exact scoped subsets, same captured entries, reset, cancellation, activation, retained receipts and executable/source hashes. Native keyboard-only scope traversal, simultaneous scope-change/Enter rendering and other platforms remain unqualified; old-scope Enter is explicitly suppressed in the UI handler.
