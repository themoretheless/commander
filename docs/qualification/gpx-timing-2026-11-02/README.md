# GPX recorded timing statistics

Continuation of the existing Strata-inspired route preview, independently extended in Commander. [GPX 1.1 point timestamps](https://www.topografix.com/GPX/1/1/#type_wptType) now feed recorded interval duration, covered distance and average speed. The upstream Strata source URL was unavailable during this pass, so no claim is made that this particular timing behavior matches Strata. Geometry, source switching, offline schematic and elevation remain on the existing bounded parser/cache path.

Only direct standard GPX point time elements are read. Timestamps require RFC3339 with an explicit timezone (Z or numeric offset); fractional seconds and pre-epoch instants are supported. Missing, malformed, repeated or nested time values do not discard valid geometry: they become missing/invalid timing owners. Naive timestamps are not interpreted in the machine's local timezone. This is a supported timestamp subset, not full XML Schema dateTime validation. KML gx time handling is unchanged and has no timing statistics in this milestone.

A timed leg needs both adjacent points in one segment and a strictly positive elapsed interval. Missing/invalid endpoints, equal/backward timestamps and segment transitions are excluded; no interpolation bridges gaps. Timing counts distinguish eligible/timed/untimed/non-increasing legs and valid/missing/invalid points. Seconds and distance are summed only over timed legs, and average km/h is timed distance divided by those seconds. Recorded stationary intervals count, so this is not moving speed or start-to-finish wall-clock duration. UI labels state the coverage and exclusions. Distance remains the existing spherical estimate.

Two new regressions cover segment gaps, missing interior timestamps, offsets/subseconds/pre-epoch dates, stationary intervals, equal/backward times, malformed/duplicate/nested data and unavailable timing. Existing size/node/point/concurrency/cancellation/stale-source bounds remain active. No dependency graph change: the already-present chrono parser is reused.

The GPX fixture has six timed points in two segments: four legs total 480 seconds, while its first-to-last wall-clock span is 3900 seconds. Independent Python XML/datetime/spherical calculation agrees on 5550.48629556 covered metres and 41.6286472167 km/h. The actual native GPX Source/Route workflow and KML control each passed 14/14 with all native effects zero. Both final frames were visually inspected: timing text, route and elevation remain visible. Captured point timestamps/statistics are compared against the source, and the control's geometry agrees while its timing is unavailable. Both existing scenes remain in CI.

All six gates passed; full suite 3287 passed / 3 ignored. verify.py rechecks gates, exact source/binary identities, scenes/effects and independent calculations. Native partial/malformed timestamp scenes, time-series speed plots, pause detection/moving speed, KML gx timing, FIT and KMZ remain open. Prior dependency audit failures and the broad 99-repository transfer objective remain open.
