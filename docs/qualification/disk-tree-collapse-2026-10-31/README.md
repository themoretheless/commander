# Disk-usage branch collapse — 2026-10-31

Independently adapts [dust's collapsed-subtree display](https://github.com/bootandy/dust#usage), cohort #82. This is interactive control over Commander's retained compressed directory tree; no upstream implementation is copied.

Directory rows with represented descendants have a separate, focusable expand/collapse button. Activating it hides descendants without navigating, mutating the scan, recalculating totals or adding filesystem reads. Leaf rows reserve the same horizontal space for consistent indentation. Collapse all closes all represented branches; Expand all clears saved choices. Collapsing preserves scroll position; changing search or publishing a new snapshot resets it as before.

Choices are keyed by full source paths and survive mode switches, query changes and Rescan for the open tool. Missing paths can retain a choice until the tool closes, so a temporary partial snapshot does not erase it. A nonblank search reveals matching rows and ancestor context even inside collapsed branches. Branch buttons and Collapse all are disabled during search; a notice explains temporary reveal, while Expand all can clear choices. Clearing search restores the saved projection. The caption states how many rows are hidden. Parent-share percentages continue to use the full retained ancestor model.

Visible CSV now appends a `collapsed` boolean to the previous 14 columns. Only rows actually shown are exported, and a closed represented branch is marked true; search-revealed rows are marked false. Raw subtree totals remain unchanged. The exporter reconstructs the projection from saved options and verifies indices, direct matches, counts and child metadata before indexing/exporting. Dirty/corrupt projections fail closed. Full JSON retains its existing schema and complete retained scope independently of collapse/search. CSV consumers that require exactly 14 columns must accept the new trailing field.
