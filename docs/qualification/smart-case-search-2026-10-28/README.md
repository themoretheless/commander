# Smart-case search — 2026-10-28

Independent adaptation of ripgrep -S/--smart-case ([primary guide](https://github.com/BurntSushi/ripgrep/blob/master/GUIDE.md), [primary semantic reference](https://github.com/BurntSushi/ripgrep/blob/master/crates/regex/src/ast.rs)), cohort repository #76. No upstream implementation copied. Commander's analysis uses the public regex-syntax AST visitor, whose traversal has constant stack usage.

New case:smart preserves the insensitive default until requested. It chooses one global policy for all case-controlled matching terms: literal uppercase forces sensitivity; literal-only lowercase terms choose insensitive matching; regex-only patterns without literals keep intrinsic case-sensitive class meaning. Name/path/content and their negative forms, masks/exclusions, extensions, literal word/line conditions and saved pane filters participate. Dates, kinds, permissions and other structural values do not. Different case modes conflict; duplicate smart modes are accepted. Existing CaseSensitive(bool) saved representations remain unchanged; SmartCase is a new predicate with expression/JSON persistence.

Regex-mode text fields analyze parsed literal nodes and bracket literal/range endpoints. Perl/Unicode/ASCII class names, capture names, comments and flags do not count as uppercase literals; decoded uppercase escapes do. Literal word/line fields keep literal analysis even in Regex mode. Inline regex flags retain normal engine precedence. The parser/visitor runs during query validation/compilation, never per result; validation reuses its resolved case setting. This is not a claim of full ripgrep regex/options parity or a performance improvement.

regex-syntax 0.8.11 was already locked transitively through regex 1.13.1. It is now a direct dependency; offline resolution changed only the commander's dependency list in Cargo.lock and upgraded no package. check.log records the offline build check.

Four focused regressions cover all text modes, structural-value exclusion, Unicode uppercase, masks/extensions/literal-word/line conditions, repeated/conflicting controls, old defaults, expression/JSON round trips, class escapes/properties/ranges/intersections, capture names/comments, decoded escapes, inline flags and real native/JSON-index/ZIP/TAR positive/negative content matrices.
