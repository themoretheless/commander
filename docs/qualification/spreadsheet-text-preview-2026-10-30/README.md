# XLSX and ODS text previews — 2026-10-30

Independent Rust adaptation of [Double Commander Office XML text-only viewing](https://doublecmd.github.io/doc/en/viewer.html), cohort #3. Its help explicitly includes XLSX and ODS. Commander now extends the existing Office text pipeline to both spreadsheet formats. No upstream implementation copied.

XLSX follows workbook sheet order and internal worksheet/shared-string relationships, including strict and transitional SpreadsheetML namespaces. Shared rich strings, inline strings, numbers, booleans, error values and ISO date values are read. Sparse row/column references preserve internal gaps and invalid/decreasing/out-of-range references or invalid shared indices reject the preview. Numeric values are preserved as stored strings without floating-point conversion. Cached formula results are shown; formulas without cached values appear as literal expressions. Formulas never execute. External relationships requested for worksheets/strings, escaping package paths, missing parts and duplicate relationship IDs are rejected. Relationships resolve only within the in-memory ZIP; no URLs or files are opened.

ODS follows table order, including row groups/header rows, cell text and cached scalar attributes, repeated rows/columns and covered cells. Internal empty gaps are retained; trailing empty cells and compact repeated empty-row tails are omitted without expansion. A million-row empty tail is explicitly qualified. Formulas lacking cached/displayed values remain literal. Both formats use sheet headings followed by tab-separated cell text in the existing plain preview, with find/copy/size/wrap controls. Hidden sheets are included in workbook order.

Bounds: compressed package 16 MiB, 4096 ZIP entries, aggregate decompressed XML 4 MiB across all requested parts, 100000 nodes per XML part, nesting 128, 128 sheets, 16384 columns and 1048576 rows per sheet, output 256 KiB. Reading, decompression and value traversal retain cancellation checks; DTD parsing is disabled. Text over a budget is rejected, not silently promoted as a full preview. Package reading/duplicate-member checks are shared with DOCX/ODT; their prior regressions remain in the full suite. Existing text-cache limits, worker ownership and file identity guards remain unchanged. No dependency added in this milestone.

Eight regressions cover equivalent multi-sheet output for both formats, shared/rich strings, cached formulas, strict namespaces, sparse positions, raw large-number precision, dates/errors, missing/external/escaping relationships, invalid cell references, ODS repetition/covered cells/formula fallback, compact empty tails, cancellation, aggregate XML budgets, DTD and depth bounds. Native XLSX and ODS scenarios each require exact two-sheet text, one find match for message and one recording copy of the exact displayed text. Fixtures are minimal generated packages, not a full Office compatibility corpus.

Limits of the feature: text-only values, not an editable spreadsheet or page-layout renderer. Styles, formatted serial dates, chart sheets/charts, pivot tables, merged visual layout and recalculation are not implemented. Main XML must be UTF-8. Unsupported/encrypted/malformed packages use the existing document error. Broader Office/peer parity remains open.
