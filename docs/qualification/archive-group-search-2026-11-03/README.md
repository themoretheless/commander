Literal, Glob, Regex and Exact searches can match full paths or filenames, with optional case sensitivity. Any matching member retains its complete group. Filtering and sorting share a cached permutation of original scan ranks; scan data, member identities and report exports stay unchanged. Changing search resets group pagination. Reset clears matching options and preserves sort. These view settings are runtime-only.

Select shown groups / Deselect shown groups operate on every member of matching groups across all group pages, including nonmatching members. Hidden groups and unrelated selection remain unchanged. All identities are validated before any mutation; these actions participate in selection undo/redo. Global scan/keeper actions and exports retain their all-scanned scope. No scan or file modification is triggered by search.

The shared bounded matcher refuses queries over 256 characters and invalid regex/glob patterns. Active search refuses non-UTF-8 member paths rather than showing a partial result; empty literal search can show all groups. Errors show no groups and disable shown-group actions. Case-insensitive text uses Unicode lowercase, not locale-specific case folding.
