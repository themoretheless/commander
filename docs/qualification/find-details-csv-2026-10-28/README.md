Independent adaptation of Double Commander's [Copy all shown columns](https://doublecmd.github.io/doc/en/help.html), using Commander's own Find metadata schema and existing CSV escaping. No upstream code copied; upstream tab-delimited output is not claimed to share this CSV format.

Details (CSV) in Copy as exports Path, Name, Kind, Size (bytes), Modified. It works for all received visible results or selected visible results in displayed order. Full paths retain virtual archive members; names remain separate basenames. Kind follows the existing file/folder entry model. Files retain exact integer byte sizes; folders leave size blank rather than exporting a placeholder or implying measured tree size. Observed modification times use RFC 3339 UTC with available fractional precision; unknown or unrepresentable times are blank. No live metadata reads are introduced.

The formatter reuses the established comma/quote/multiline CSV escaping and formula-prefix handling, including headers and separate full path/name columns. Paths retain the existing lossy UTF-8 conversion for non-UTF-8 names. This is metadata text export, not a reloadable identity/selection format; duplicate virtual member paths may yield duplicate rows. Empty copy scopes still produce no clipboard request, and streaming/cap limits remain visible-result snapshot semantics.

Existing pane CSV keeps its previous whole-second output for valid timestamps; the new Find CSV uses available fractional seconds.
