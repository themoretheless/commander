# Protect archive filenames at any depth, with explicit case mode — 2026-11-03

Independent adaptation of cohort #85 [fclones keep-name versus keep-path](https://raw.githubusercontent.com/pkolaczk/fclones/main/fclones/src/config.rs). The archive copy-protection row adds Filename only and Match case. Full-path, case-sensitive matching remains the default. Filename only matches the final name at any folder depth, so *.txt can protect both root and nested files without a recursive path pattern. Turning off Match case uses the same lowercase-based pattern/candidate matching as existing archive filters; it is not a claim of locale-specific or full Unicode case folding.

Both controls feed the shared bounded archive glob matcher. They change pending policy only, leaving the current selection intact until a per-group/global Select copies action. Empty protection still disables matching regardless of these options. Every protected match remains a keeper even above the minimum count; the selected ordering fills any remaining keeper slots.
