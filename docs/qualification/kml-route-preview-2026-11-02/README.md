# KML line and track preview

Continuation of the independently implemented [Strata route-preview capability](https://github.com/lgse/strata/blob/ede64d928ab6723c71c774948fbf07bc24616cdb/src/services/route_preview.rs). Commander now recognizes `.kml` in the existing Route / Source preview, reads standard LineString coordinates and Google gx:Track positions, and shares the offline schematic, segment-preserving spherical distance estimate and recorded elevation profile with GPX. MultiGeometry and gx:MultiTrack retain separate source segments. KML 2.2 and namespace-free KML are supported; gx elements require the real Google extension namespace.

Coordinate order, sparse positions and altitude modes follow the [KML reference](https://developers.google.com/kml/documentation/kmlreference/) and [altitude-mode documentation](https://developers.google.com/kml/documentation/altitudemode). Only explicit `absolute` altitude enters the elevation profile. Default/clamp/relative modes do not become invented sea-level heights. Missing gx positions create gaps instead of guessed interpolation; this choice is shown in the UI. Unknown/ambiguous altitude modes and malformed tuples are rejected. Lines must belong to a Placemark through standard geometry/feature containers; data inside ExtendedData, foreign namespaces, polygons or linked resources does not create a supported line. Coordinate text split by comments is preserved.

The existing complete 256 KiB text snapshot, XML DTD refusal, 50,000-node / 10,000-point bounds, two-parser admission, cancellation, per-pane Arc cache and stale-content protection remain shared. No dependency or network access is added. GPX attribute whitespace is accepted. Both file types show their actual parsed format in route statistics.
