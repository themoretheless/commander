# Focus-owned diff search shortcuts — 2026-10-31

Adapts [Double Commander Differ shortcuts](https://doublecmd.github.io/doc/en/shortcuts.html), cohort #3: F7 / Ctrl+F focus search, F3 finds next and Shift+F3 finds previous. Commander additionally supports the platform Command+F gesture on macOS. Query text/settings remain retained; these shortcuts reuse cached row results, cyclic navigation, hidden-context expansion and selected-row reveal.

The existing early diff key owner handles these keys before pane command mapping. Modal priority, unrelated text inputs, inactive diff keyboard ownership and popups retain their guards. The query uses a stable widget ID: search shortcuts work both from the active diff and within its query. Other query editing keys remain with TextEdit; Enter is handled by the toolbar. F3 with Ctrl/Alt/Command and F7 with extra modifiers are not search actions. No file opens, directory creation or source mutation are introduced by the transferred actions.

A new actual TextEdit regression exposed that single-line Enter surrendered focus before the toolbar's old `has_focus` check; the failed attempt is retained in `before-enter-fix.log`. Enter is now consumed before drawing the focused input, so it reliably advances to the next result without changing the query. Keyboard-requested reveal is delivered once through modal-owned state, not a retained context callback/job. The query-length error path also clears stale search highlight ownership.
