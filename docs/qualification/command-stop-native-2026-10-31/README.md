# Native Run/Stop qualification — 2026-10-31

Follow-up to the [custom-command Stop race repair](../command-stop-race-2026-10-31/README.md). This slice adds native UI regression coverage to an existing command feature; it does not add another user command or claim parity across the 99-repository cohort.

The new `per_item_stop` scene seeds the retained dialog context with two owned temporary ordinary files, then sends six pointer phases (hover/down/up on Run, then on Stop) through the native egui event path. It waits for the first invocation's on-disk start marker before stopping. The command writes its marker and stdout, sleeps, then would overwrite its input if allowed to finish. Final readiness requires cancellation after exactly one attempted/completed invocation, a retired run, `ready` in captured stdout, both original files unchanged, the first marker present and the second marker absent. It records the resulting report and filesystem observations before fixture cleanup. Stop's rectangle probe is compiled only for tests/visual QA; the production button handler is unchanged.

Fresh native capture passed **16/16**, and the framebuffer was inspected: the dialog shows “Per-item command cancelled” and 1/2 completed, with Run available again. Independent assertions verify all six button phases, cancellation/report agreement, preserved file contents, absent second-start marker and matching build/launch/core SHA-256 hashes. Native effect-port counters are all zero; shell creation and fixture writes are real host operations and are not counted by those ports. This qualifies the native egui input path; it does not claim physical mouse automation or a system clipboard write. `assert-native.py` reads the unique output path recorded in `native-launch.json` and retains its checks/results in this directory.

The scene is included in the macOS visual-QA CI matrix and the stable scene registry (66 scenes). **3045 tests passed, 3 ignored, zero failed**. All six checks passed: visual-QA build/full tests, all-target Clippy with warnings denied, default check, formatting and diff whitespace. Exact results are in `checks.json` and the six logs. Ordinary Unix same-group cancellation is covered here; intentionally detached sessions, arbitrary daemon containment and other platforms remain outside this evidence. No performance or zero-latency guarantee is claimed.
