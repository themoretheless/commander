# FB2 book text previews — 2026-10-30

Independent Rust adaptation of [ranger FictionBook text conversion previews](https://github.com/ranger/ranger/blob/master/ranger/data/scope.sh), cohort #30. ranger delegates FB2 conversion to another program. Commander decodes and parses FB2 directly in Rust, with no converter subprocess or upstream code copied.

The new reader accepts the FictionBook 2 namespace independently of prefixes, includes the optional book title, preserves body order (including named notes bodies), section/title paragraphs, inline text, verse lines/stanza gaps, explicit empty lines and table-cell text. Images become inert placeholders; binary payloads and unrelated description metadata are not included. Link attributes are ignored and no embedded/external resources are opened. Existing text size/wrap/line/find/copy controls operate on the extracted text. FB2 classifies as Documents and has a text-only preview label.

UTF-8, UTF-16 LE/BE with BOM or the XML declaration signature, and explicitly declared Windows-1251/1252, KOI8-R/U and ISO-8859-5 are supported. No undeclared legacy-codepage guessing. Declared encoding and BOM/signature must agree. Strict decoding uses [encoding_rs](https://docs.rs/encoding_rs/0.8.42/encoding_rs/struct.Encoding.html#method.decode_without_bom_handling_and_without_replacement) and rejects malformed sequences without replacement characters; this milestone adds encoding_rs 0.8.42 and its locked dependencies. UTF-16 generic declaration requires an endian BOM/signature. Unknown/unsupported declarations fail.

The existing preview worker/cache/request ownership and before/after path/open-handle identity checks remain. Raw input and decoded XML each allow 4 MiB; extracted text 256 KiB. Ordinary text limits are unchanged. Shared XML parsing disables DTD and bounds nodes/depth; traversal checks cancellation. Oversized output is rejected without publishing partial text. There is no automatic image/base64 decoding.

Five regressions cover a Windows-1251 fixture with XML Unicode references, exact book/body/verse/table output and skipped payloads; every advertised codepage and UTF-8/16 BOM/signature combinations; invalid byte sequences, unsupported declarations and conflicting BOMs; namespace aliases, inert links/images/empty lines; malformed roots/DTD, raw/output limits and cancellation during traversal. Existing document-kind coverage now includes FB2. Full locked visual-qa suite **2699 passed, 0 failed, 3 ignored**. The initial raw-string test compilation error is retained separately and was corrected before this run. Native readiness requires exact extracted Windows-1251 book text, one find match and one exact recording copy.

Limits: text-only FB2, not ebook layout/rendering, images, DRM or compressed FB2 archives. Binaries count against the XML/input budgets even though their content is omitted. Formatting/paragraph styles and note-link navigation are not rendered. Unsupported/malformed documents use the shared document error. Broader viewer/peer parity remains open.
