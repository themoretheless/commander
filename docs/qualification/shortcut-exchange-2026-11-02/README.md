# Shortcut set exchange

Commander extension of the Kiorg-inspired configurable-shortcut transfer (cohort #1). F1 now offers **Import / export shortcuts**. **Copy applied set** exports only the active bindings through the existing clipboard port. Paste a Commander shortcut-set JSON document into the exchange field and choose **Load into draft**; validation completes before the editable draft is replaced. **Apply shortcuts** remains the sole activation step and uses the existing session persistence path.

The independent Commander format is `commander.shortcuts`, version 1, containing a bindings array. It is not Kiorg's TOML format. Documents are capped at 64 KiB; row/key/command bounds and existing command/prefix validation remain shared. Unknown versions/fields, duplicate JSON fields, unknown commands, invalid keys and conflicting/prefix bindings are rejected. An invalid import preserves both the current draft and active preferences. Export uses the applied snapshot even when the draft is invalid or different. Empty sets round-trip; unreadable/future applied preference objects cannot silently export as an empty valid set. Other session preferences are never included.

The F1 reference now draws only visible fixed-height rows and gives key/command columns usable widths. This replaces the observed narrow wrapping and avoids exposing every clipped reference row to the native accessibility tree. The exchange area stays collapsible and the Close button stays outside the main scroll area.
