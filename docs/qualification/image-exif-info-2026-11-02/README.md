# Image EXIF in Get Info

Independent adaptation of the image metadata capability inspected in [Strata raw metadata](https://github.com/lgse/strata/blob/ede64d928ab6723c71c774948fbf07bc24616cdb/src/sandbox_helper/raw_metadata.rs). Commander uses the upstream [pure-Rust EXIF parser](https://github.com/kamadak/exif-rs) through its own inspector lifecycle; no Strata implementation copied. BSD-2-Clause notices for the parser and mutate_once are preserved in `data/licenses` and the project third-party catalog.

Get Info now displays available camera/lens, recorded capture/digitization time, exposure, aperture, ISO, focal length, flash/white balance, orientation, stored pixel dimensions/color space and GPS coordinates/altitude/date. Values use the parser's EXIF units, without timezone inference, maps, resource requests or metadata editing. Missing tags are omitted. Text is bounded to 512 UTF-8 bytes plus a truncation mark; control characters are replaced with spaces.

Only a supported regular image inspector admits a job. Listing-native path/size/mtime/object/change identity is retained, checked before opening, on the open handle and after parsing. Unix opens are nonblocking and reject symlink following; symlink inspectors retain their existing lexical filesystem properties without this read. A worker reads at most the first 2 MiB in cancellable 32 KiB chunks, with two active metadata readers and a ten-second UI timeout. Parsing never decodes pixels. The inspector owns its channel/cancel token; closing or replacing it prevents late publication. Errors offer explicit Retry, with no automatic retry loop. Kernel-blocked IO remains cooperatively cancellable; the active-reader cap bounds such jobs.

Admission includes JPEG/JPE, PNG, TIFF, WebP, HEIC/HEIF, AVIF and DNG. Native qualification is a real JPEG with embedded little-endian TIFF EXIF; the other admitted containers need additional end-to-end fixtures. Metadata outside the prefix is explicitly unavailable/limited, not treated as proof that no metadata exists. Broader RAW, IPTC/XMP, audiovisual properties and full Strata parity remain open.

Four focused tests cover common fields/units/GPS, malformed/missing data, bounded output/control text, real-file change/link/cancellation/read-limit behavior and retired-owner late results. Full suite: **3221 passed / 3 ignored**; all six build/test/static gates passed. The ExifInfo and neighboring FileIdentityInfo native scenes each passed **14/14** with zero external-effect calls; both final frames were visually inspected. The EXIF scene opens Get Info through the palette and scrolls until GPS altitude is fully inside the clip rectangle. `verify.py` independently decodes JPEG markers/TIFF IFDs with Python's standard library and matches all 14 displayed fixture values, verifies GPS visibility, neighboring raw filesystem identities, PNG dimensions and final source/binary/core/validator hashes.

The first capture ended during smooth scrolling and showed camera fields; it is preserved under its original capture directory with earlier launch records/gates under `superseded-scroll-capture`. The final scene waits for measured GPS visibility without extending the timeout. Final captures: `native-captures/1793598896128296000/exif_info` and `native-captures/1793598927704029000/file_identity_info`. CUA attachment returned after captured processes had exited; manifests were inspected instead of relaunching them.
