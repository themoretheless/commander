# Compact context in text diff — 2026-10-31

Extends hunk-oriented comparison review documented by [Midnight Commander](https://github.com/MidnightCommander/mc/blob/master/doc/man/mc.1.in#L2830), cohort #40, and Commander's previously transferred difference navigation. Compact context controls/gap projection are a Commander-specific extension, not a claim of mcdiff display compatibility or a copied upstream implementation.

**Compact diff** is off by default. When enabled, **Context lines** (0–50, default 3) keeps unchanged rows on either side of each difference block, merging touching/overlapping contexts. Every changed row stays represented. Hidden equal stretches become count-labelled **Show** markers; clicking reveals that exact retained stretch. Expanding does not read files, rerun the diff or change selected difference/source coordinates. Mode/context changes clear individual expansions and recenter the selected block. Turning Compact diff off restores all retained rows, and turning it on again starts folded.

The projection stores contiguous chunks rather than a second per-row copy of the diff. Original row IDs remain authoritative for highlighting, First/Previous/Next/Last and focused Alt navigation; jumps map those IDs into current display coordinates. Revealing a hidden equal stretch preserves its insertion point for reading; subsequent difference navigation uses the updated map. The renderer still virtualizes display rows, with fixed-height interactive gap markers. Its visibility probe now records actual original rows, avoiding a bounding-range claim over hidden gaps.

The status counts display rows (including gap markers) against the retained unified edit-script rows, and counts hidden unchanged lines separately. These are not the two input files' independent line totals. Text, end-of-line diagnostics, change counts, source line coordinates and bounded read/diff owners remain unchanged. No source edits, merge/patch operations or new filesystem reads occur while folding or expanding. Identical inputs retain their existing identical message; they do not produce fake differences. New comparisons start with default view state.

The initial green qualification, which restored the full view for its final screenshot, is preserved in `before-compact-capture/`. The final scene additionally refolds so the delivered framebuffer can be inspected in the actual compact mode.
