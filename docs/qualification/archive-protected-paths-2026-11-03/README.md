# Protect matching archive paths when selecting extra copies — 2026-11-03

Independent adaptation of cohort #85 [fclones keep-path patterns](https://raw.githubusercontent.com/pkolaczk/fclones/main/fclones/src/config.rs). The archive content-group replica controls add Protect paths (glob). Every matching scanned member is kept by the extra-copy selection actions, even when protected matches exceed the requested count. The count is a minimum total: if protection keeps fewer copies, the existing first/last/time/depth order fills the remaining slots from unprotected members. Protected keepers are deselected, redundant members selected and unrelated selections preserved.

The shared archive glob matcher provides full case-sensitive archive-relative matches, literal separators, ** recursion, alternatives/classes/escapes and a 256-character compilation bound. Empty disables protection. Matching uses exact UTF-8 member paths; unrepresentable paths refuse atomically instead of using a lossy conversion. Invalid/oversized patterns disable both per-group/global extra-copy controls and are rejected by the backend before mutation. The field allows enough input to show an over-limit error; no pattern is applied simply by editing it. Existing identity/overlap/type validation, all-page/hidden-member scope and no-I/O selection ownership remain unchanged. Other explicit selection actions remain available.

The new Rust matrix covers protected counts below/above the minimum, all-protected/no-protected cases, case sensitivity, Unicode, classes/alternatives, separator recursion, both group/global scopes, unrelated selection, malformed/oversized patterns, non-UTF-8 refusal and stale identities. Native TAR retains the earlier timestamp/depth and report checks and types exact, * and ** patterns. Ten receipts assert pending versus applied state, duplicate-name protection exceeding the keep count, separator behavior, all protected members, both disabled controls on invalid input, recovery and independent group/global application. Python independently computes protected subsets and keeper selection from tarfile/PurePosixPath/regex data. ZIP retains the existing password/group/export regression; protection-specific native interaction is qualified on TAR.
