# XXH3-64 and XXH3-128 checksums — 2026-11-03

Independent integration inspired by cohort #85 [fclones XXH3 support](https://github.com/pkolaczk/fclones/blob/main/fclones/Cargo.toml). Commander now computes default-settings XXH3-64 and XXH3-128 using xxhash-rust 0.8.19, in the same fresh bounded/cancellable read pass as the existing algorithms. One streaming state yields both digests. Source identity checks and refusal of symlinks/special/mutated files remain shared; cancelled/error rows do not expose either new digest.

Both algorithms appear in the checksum and list-verification selectors, row/detailed reports, Hex and canonical Base64 comparison/copying, and GNU-style relative/absolute list export. Numeric digests are formatted in canonical big-endian hexadecimal, including leading zeros. Tagged lists accept XXH3 / XXH3-64 / XXH3_64 and XXH128 / XXH3-128 / XXH3_128; recognized filename extensions and SUMS names distinguish the widths. Unhinted 32-digit lists are now ambiguous between MD5 and XXH3-128 and require an explicit algorithm, tag or filename; unambiguous 16-digit lists can identify XXH3-64. The UI identifies XXH3 as non-cryptographic. No benchmark/speedup claim is made: all algorithms still share the existing full checksum pass, and the BLAKE3 internal content identity remains unchanged.

The official xxHash C v0.8.3 header generates 23 deterministic reference vectors spanning empty/abc, short-input branches, 240/241-byte boundaries and 64 KiB read boundaries. reference.json records the header URL/hash, C wrapper hash and compiler; generate_reference.py downloads into ignored target/xxh3-reference and reproduces vectors.json. C code is not linked into Commander. Two Rust integration regressions qualify streaming values, Hex/Base64 comparison, display, full list export/reverification, cancellation visibility, aliases/hints, wrong widths and mismatch handling. Prior mutation/refusal assertions now also check the new fields.

All seven final gates passed: audit, visual-qa build, 3473 tests passed / 0 failed / 3 ignored, strict Clippy, ordinary check, fmt and diff.
