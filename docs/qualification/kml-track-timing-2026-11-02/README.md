# KML gx:Track recorded timing

Continuation of Commander's Strata-inspired route preview and GPX timing, using [Google's gx:Track reference](https://developers.google.com/kml/documentation/kmlreference#gxtrack). Direct KML when and gx:coord arrays are matched by original position, including empty coordinate placeholders. Only equal array counts permit time assignment. Mismatched counts leave geometry intact but mark rendered points as invalid timing; wholly absent when values remain missing. Empty/malformed/nested timestamps are invalid. Foreign-namespace when elements are ignored.

Sparse coordinates retain existing segment gaps and never shift subsequent timestamps. No time/distance is interpolated across these gaps, between geometries or across separate tracks/MultiTrack members. LineString points remain untimed. This intentionally differs from Google Earth interpolation; existing offline geometry behavior stays intact. Timestamp parsing shares GPX's explicit-zone RFC3339 subset. The same adjacent-positive-leg summary shows covered seconds/distance/average and timestamp/leg counts when KML timing data is present. Recorded stationary intervals count; this is not moving speed or total wall-clock duration.

Two regressions cover sparse-index preservation, unequal arrays, malformed values, mixed LineString/Track coverage and foreign namespaces. Existing GPX timing, segment, date-line, altitude, bounds/cache/cancellation cases remain covered. The native KML Source/Route scene now contains one untimed three-point LineString and one timed three-point track; the GPX timing scene is the control. Source XML and captured timestamps/statistics support an independent Python alignment/time/distance/speed verifier.

No dependencies changed. Timezone-free/coarse KML dates, interpolation, moving speed, animation, FIT and KMZ remain outside this milestone. The initial test-source quoting/build failure is retained in initial-failed; final gates use the corrected source. Previous dependency audit failures and the wider cohort transfer objective remain open.

Final validation: all six gates passed, full suite 3289 passed / 3 ignored. Native KML and GPX Source/Route scenes each passed 14/14, all effects zero. Independent XML/datetime/geometry verification agrees on KML's three valid/three missing timestamps, two timed legs, 300 seconds, 2775.24314778 metres and 33.3029177734 km/h; the GPX control remains 480 seconds and 41.6286472167 km/h. Geometry/elevation/segment boundaries match across fixtures. Source/binary hashes agree; both final frames were visually inspected and existing CI entries retain both scenes. Native sparse/malformed/mismatch examples remain additional coverage beyond the parser regressions.
