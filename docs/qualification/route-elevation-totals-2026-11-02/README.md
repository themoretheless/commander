# Recorded route elevation gain/loss

Commander extension of the existing Strata-inspired GPX/KML route preview. Alongside the recorded elevation range/profile, it now shows summed positive and negative adjacent elevation differences and covered/eligible leg counts. Only neighboring points within one segment with both elevations present contribute. Missing elevations and segment/geometry/sparse-coordinate gaps are never bridged. A fully flat covered leg yields zero gain/loss; no covered legs yields unavailable, not zero. KML continues to admit only absolute altitude into this measurement; relative/clamped altitude is not resolved against terrain.

Totals are raw recorded samples with no noise filtering, resampling, interpolation or terrain correction. They are not a certified physical ascent/descent estimate. UI labels state raw samples and excluded gaps, and retain the known-point count. The route canvas reserves room for the additional line while preserving the elevation plot. Parsing, source switching, timestamps, geometry and original-source limits remain shared.

Two regressions cover exact GPX/KML totals, missing interior elevations, isolated points across segment boundaries, unavailable versus flat-zero results and excluded relative KML altitude. The existing native GPX and KML Source/Route scenes retain elevation_stats in their snapshots. Independent Python XML calculation sums the source by segment and compares 90 m ascent / 60 m descent and all coverage counts in both captured formats. No dependencies were added. Filtering/smoothing, sensor accuracy, terrain, native missing-altitude scenarios, FIT/KMZ and the wider cohort parity remain open; prior audit failures are unchanged.

Final validation: all six gates passed, full suite 3291 passed / 3 ignored. GPX/KML Source/Route scenes each passed 14/14 with zero effects. Independent source XML verification agrees on every elevation, exact gap-aware totals/coverage and retained time/distance/speed metrics. Source/binary hashes agree. Both final frames were visually inspected; summaries, route and elevation profile remain readable. Existing CI scenes include the new snapshots.
