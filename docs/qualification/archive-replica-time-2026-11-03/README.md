# Keep newest or oldest matching archive copies — 2026-11-03

Independent adaptation of cohort #85 [fclones replica priorities](https://github.com/pkolaczk/fclones#removing-files). Archive SHA-256 content groups now offer Newest timestamps and Oldest timestamps alongside First entries and Last entries. Labels describe copies retained, while fclones' priority labels describe replicas removed. The configured count applies to global and individual-group selection actions. Changing count/order leaves selection untouched until applied.

Timestamp modes use the member's declared modification time already retained in the archive listing; they do not use the archive file's own timestamp or reread payloads. Known dates precede missing dates in both modes. Equal dates, and unknown dates among themselves, use the lowest original entry index. Subsecond and pre-epoch times compare without narrowing. Exact original index/path/size/type resolution still validates all affected identities before selection changes; keepers are deselected, redundant rows selected and unrelated selections preserved. Hidden members and all pages remain included. This is selection only; archive mutation/deletion and pairwise content comparison remain separate open work.

The new Rust regression exercises both group/global paths, counts 1/2/4/above-size, stable ties with shuffled indices/duplicate names, partial/all missing timestamps, nanoseconds, pre-epoch times, unrelated selection and atomic stale-identity refusal. The dated TAR fixture preserves the previous eleven members, PAX Unicode paths and duplicate names/payloads while deliberately making timestamp order differ from entry order. Native TAR performs real newest/oldest policy and selection clicks, recording pending edits and applied keeper identities. An independent Python tarfile/hash oracle recomputes dates, groups and keepers. The ZIP native scene retains its existing password/group/export workflow; timestamp-specific native interaction is qualified on TAR, while the format-independent selection logic and existing ZIP metadata tests cover the shared path.
