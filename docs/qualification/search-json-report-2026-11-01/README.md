# Search result JSON report

Independent adaptation of [ripgrep's structured search output and summary](https://github.com/BurntSushi/ripgrep/blob/master/crates/core/flags/defs.rs), cohort #76. Commander emits a single versioned JSON document, not rg's JSON Lines protocol. No upstream implementation copied.

Find adds **Report (JSON)** to its existing Copy as picker. Full-visible and visible-selected scopes follow the actual displayed/pivot order and omit hidden rows; full reports also work when no rows are visible. Reports bind to last_query's normalized expression/mode/root and current retained generation/source, never the editable draft. A draft_differs flag and pending_rerun state distinguish new/invalid drafts. Explicit observed completion is false during a run and on cancellation/disconnection; partial also includes truncation, skipped coverage and archive failures. A changed draft does not invalidate a completed old query's retained snapshot.

Rows retain structured native or archive/member/index locations, native IDs where known, provider-listed sizes/times and score/explanation/Unicode-character ranges. The archive container is distinct from its member, even if names include exclamation marks. Display names can be lossy labels; paths encode exact UTF-8 strings, Unix bytes as hex, or Windows UTF-16 units for unpaired surrogates. Paths are validated without touching the filesystem. Native paths/root must be absolute; archive members must be enclosed relative paths. The JSON output writer is bounded to 1 MiB, and a refusal yields no clipboard value. The UI reports refusal through its existing action-error surface; other copy formats retain their behavior.
