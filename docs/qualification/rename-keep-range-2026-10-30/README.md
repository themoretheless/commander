# Keep a character range during batch rename — 2026-10-30

Independent adaptation of [Double Commander filename/extension range extraction](https://doublecmd.github.io/doc/en/multirename.html), cohort repository #3. No upstream code copied. Commander exposes a single clamped grapheme range with Remove/Keep actions; it does not implement the full placeholder grammar, multiple concatenated ranges or plugin placeholders.

The Range checkbox enables positional editing. Remove retains the previous behavior; Keep retains only the selected range. Skip counts whole grapheme clusters from the chosen edge and Count selects towards the other edge. Both edges preserve forward text order. Short ranges clamp; beyond-end selections are empty. The chosen Character edits scope controls whether the stem, raw extension or whole name is extracted. Directories skip Extension scope as before. Default Stem scope preserves file extensions, so an empty extracted stem may become a valid dotfile; final whole-name emptiness and all duplicate/sibling collisions still use the existing guards.

Example: Name stem / Keep / Skip 4 / Count 8 maps IMG_20261030_raw.jpg to 20261030.jpg from either edge. Extraction runs after replacements and before insertion, case, decoration/counters and final cleanup. Whole grapheme clusters, including combining sequences and emoji, remain intact. Existing range fields/bounds are reused; a new action defaults to Remove and is omitted in legacy-compatible serialization.
