# Effective workspace shortcut hints and search

Continuation of Kiorg's configurable shortcut presentation: its [shortcut display tests](https://github.com/houqp/kiorg/blob/50aea44c9b4308b98f757574c527b7e0d3a344fe/crates/kiorg/tests/ui_shortcut_display_test.rs), cohort #1, show hints derived from actual configured bindings. Commander now independently derives effective workspace keys for the F1 reference, command-palette rows and lower action bar from the applied compiled configuration.

Custom sequences appear before still-available built-in keys. If a custom binding intercepts a default key as either a complete action or a sequence leader, that old key disappears from the former command. For example, binding F5 to Reverse sort order shows F5 there and removes F5 from Copy. Copy remains accessible by its button or palette command. The F1 reference marks a command whose default was shadowed and has no alternative as Unassigned; it also includes navigation bindings. Unapplied/invalid drafts do not change hints. Disabled future/malformed saved preferences retain default hints, matching the default input handler. Hints explicitly describe workspace keys; dialogs/viewers keep their own input.

Command search now includes each effective shortcut, so typing `>Alt+G H` finds Toggle hidden files and `>F5` ranks the assigned Reverse sort order first. The old Copy binding no longer contributes an F5 metadata match. Label/keyword matching, exact-label priority, stable tie order and usage ranking remain shared. Other fuzzy label matches can still appear (the fixture also matches Go to folder tab 5); searching a key is not an exclusive key lookup. Commands outside the published palette catalog remain outside this search.

F1/palette key labels truncate with complete hover text. The action bar shows a bounded primary key and an alternative-count suffix, with the full list on hover. Presentation performs no file I/O. No binding or command execution rules changed.
