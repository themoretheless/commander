Strict UTC dates/RFC 3339 offsets and fractions use the shared date parser in every matching mode and saved query. Unsupported platforms, archived members and old/invalid cache records stay unknown and count as skipped; no other timestamp or container metadata is substituted.

Restoration needs no source I/O, so cached observations can outlive deleted files. The metadata serialization bound includes the worst-case field.
