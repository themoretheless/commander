# Favorite navigation destinations — 2026-10-31

Independently adapts [Nautilus folder/sidebar tab navigation](https://help.gnome.org/gnome-help/files-browse.html), cohort #22, to Commander's dual-pane workspace. No upstream implementation is copied.

Favorites context menus now offer **Open in other panel**, **Open in new tab** and **Open in background tab**. Middle-clicking the row requests a background tab. Normal primary click retains active-panel folder navigation. The action captures the original bookmark path; it does not derive a destination from the current cursor or selection, change bookmark metadata, assign a slot or persist a different label.

The workspace requires an existing favorite with an absolute path, then uses the normal tab lifecycle and guard owner. Foreground tabs open beside the current one and become selected; background tabs insert beside it while retaining the live pane/tab, source directory, query and preview. The source tab remains available through normal tab switching. Other-panel navigation changes only the opposite root, keeps the active side/source directory/query/preview, invalidates cross-pane presentation and clears obsolete destination preview/drag state. The eight-tab cap applies only to tab creation; a full tab group still permits other-panel navigation. Pending operations awaiting a decision, active deletion and pending UI modals block these new navigation requests. Existing running-transfer ownership remains unchanged; this is not a blanket prohibition on navigation during all background jobs.

The renderer clears a pane tool only when it covers the requested foreground/other destination. Background opening retains a covering tool. Failure emits an informational notice instead of partially opening tabs. No synchronous existence probes are added: foreground/other navigation uses the existing asynchronous listing owner, and background slots remain lazy. Missing targets report through normal panel listing behavior. Opening a favorite does not rename or modify its folder data.
