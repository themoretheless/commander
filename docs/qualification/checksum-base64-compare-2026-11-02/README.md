# Explicit expected-digest Base64 comparison

Commander extension of the PeaZip-inspired Base64 output workflow. Expected values now have an explicit Hex/Base64 selector. Hex remains default and is restored for each new checksum calculation. Switching the selector reinterprets the current input without modifying it. Base64 compares digest bytes in displayed hex byte order using the standard padded alphabet; it is case sensitive, trims only surrounding whitespace and refuses interior whitespace, URL-safe symbols, missing/excess padding, nonzero trailing bits, wrong decoded width and excessive text before decoding. Availability uses the existing single-result guard. Reports/checksum lists keep hexadecimal formats.
