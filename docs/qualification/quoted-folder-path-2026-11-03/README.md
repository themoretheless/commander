# Quoted folder paths — 2026-11-03

Independent Rust adaptation of cohort #2 [Nimble Commander's quoted Go To Folder paths](https://magnumbytes.com/whats-new/). A leading ASCII single or double quote selects Path mode in the omnibar. One matching outer pair is removed by the shared lexical parser; spaces inside it, including a trailing space in a directory name, remain literal. Bare quoted names and explicit relative forms resolve from the native folder captured when the dialog opened. Absolute and tilde paths retain existing handling. Unmatched/mismatched quotes show a specific error and submit no filesystem probe; empty enclosures and NUL are refused.

This is enclosure handling rather than shell syntax: backslashes, embedded quotes and command-looking text stay literal; no variable expansion, command substitution, shell escaping/concatenation or execution is added. Unquoted path/name modes retain their grammar; a leading quote now explicitly means a path. Paths with inner quotes can use the other enclosure. Tilde expansion still happens after removing an enclosure, including single quotes.

The asynchronous probe owns raw input and the captured relative base. Input edits retire old work/results; Go consumes only the exact current validated binding. Relative resolution now returns native PathBuf rather than converting the base to a lossy string, and runs when the controller input changes instead of on each UI frame. Native non-UTF-8 base identity is covered on Unix. Filesystem validation/canonicalization remains on the existing bounded shared worker lane; the parser does no filesystem checks.

Three new regressions cover lexical enclosure/error/literal behavior, omnibar mode routing and native relative resolution, and debounce/binding/stale-completion refusal. Existing quote-related and pending-submit tests remain. Seven final gates passed: audit, build, 3542 tests (0 failed, 3 ignored), Clippy, default check, formatting and diff. Default compilation retains its two preexisting warnings; feature Clippy is clean.

Native macOS Miller QA retains earlier navigation/tab/pin/opposite-folder steps, then types an unmatched quoted absolute path and presses Enter without leaving the source, completes the double-quoted path to `Design/ space dir `, and uses single-quoted `../../column-A` from that directory. Three independent receipts prove refusal, exact trailing-space identity, relative navigation from the new opening folder, unchanged opposite-pane path, active side and closed dialog after success. Canonical paths are compared separately from typed lexical paths, preserving the existing filesystem probe's symlink-resolution behavior. All 14 native framebuffer checks passed; final frame inspected, zero external native effects. Quoted tilde and native-byte bases have unit coverage; broader platforms and full shell-quote compatibility remain outside native qualification.
