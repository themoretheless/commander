# Regex and whole-word table filters

Independent adaptation of cohort ripgrep search concepts: https://github.com/BurntSushi/ripgrep . CSV/TSV table previews now expose Regex and Whole words, reusing the existing Rust preview pattern compiler rather than invoking an external tool or copying upstream application code.

Patterns match inside individual selected cells, never across cell boundaries. Whole words uses Unicode regex word boundaries (underscore belongs to a word), composes with literal/regex mode, and disables Fuzzy; enabling Fuzzy disables Regex and Whole words. Regex disables Fuzzy. Match case and Smart case retain the shared preview policy, including uppercase syntax in Smart case. Column scope, complete-row exclusion, heading retention, source-record identity and sorted export remain shared. Blank/whitespace queries show all rows; outer query spaces remain trimmed.

The shared compiler bounds regex and DFA caches to 1 MiB and nesting to 32; queries remain bounded at 256 characters. Compilation runs only when the cached row order is rebuilt. Invalid expressions clear the result order and retain an explicit error across frames, including inverse mode, so visible-record copying cannot publish stale/invalid results. Changing source resets the view/error; ordinary editing rebuilds it. Preview data bounds remain 256 KiB/500 records/64 columns. No dependencies or source-file writes added.

Regressions cover Unicode word ownership, underscore exclusion, anchored case-aware regex, scoped cells, inverse mode, cross-cell nonmatching, free-spacing comment handling, invalid/nested/overlong patterns, and actual egui pointer mode switching with mutual exclusivity and restored matching rows. Existing scope/export/cache/pane tests remain in the full suite. Native app layout and OS pasteboard qualification remain open for these new controls; headless pointer checks do not establish those gates.

Final validation: six gates passed, 3297 tests / 3 ignored. Native baseline table workflow passed 14/14, with one recorded clipboard call and zero other effects; source/executable/launch hashes agree. Final frame inspected: new controls and table visible without overlap at 1280x760. This qualifies the baseline Source/Table, heading/sort/filter/copy round trip and stable layout; it does not qualify native Regex/Whole words/scope/exclusion interactions, error layout or OS pasteboard.
