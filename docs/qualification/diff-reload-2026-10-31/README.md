# Reload retained text-comparison operands — 2026-10-31

Independent adaptation of [Double Commander Differ Reload files](https://doublecmd.github.io/doc/en/shortcuts.html), cohort #3. **Reload compared files** and focused **Cmd/Ctrl+R** reread the two paths retained when the comparison opened. They do not resolve the current cursor or select a different pair. The button is available in changed, identical and error states, allowing recovery after external repair.

Reload uses the same regular-file, UTF-8, 2 MiB-per-file read guards and bounded diff computation as Open. New lines, source-number coordinates, change blocks, context projection and search results replace the previous snapshot. Compact mode/context size, line-number display and query/case/whole-word/regex options remain; individual gap expansions, jump input/target, previous match index, scroll and selected difference reset. The first new change becomes the selected difference, with its normal reveal; a retained search query is refreshed but does not take highlight ownership. Error reloads clear stale success rows/coordinates/results and show the existing actionable message. Identical files use the existing identical message. Reload is synchronous within the original bounded comparison owner, not an automatic watcher or a coherent cross-file filesystem snapshot.
