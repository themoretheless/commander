# Archive glob filtering — 2026-10-30

Independent adaptation of [fd glob matching](https://github.com/sharkdp/fd/blob/master/doc/fd.1) (`--glob`), cohort #77. The archive browser now exposes a separate Glob mode using [globset](https://docs.rs/globset/0.4.21/globset/), resolved at 0.4.21 with default features disabled. Cargo added globset and bstr to the existing lockfile; no upstream executable is run.

Glob matches the entire chosen candidate, with *, ?, classes, brace alternatives and backslash escapes. With full-path scope, literal separators prevent ordinary wildcards from crossing '/', while **/ can span zero or more directory components. Filename only applies the mask to the final component at any depth. Query edge spaces are preserved; blank input retains the established unfiltered behavior. Wildcards/classes follow globset's byte semantics: ? matches one byte of the UTF-8 comparison text, not one Unicode scalar; the UI/README explicitly point users to Regex for Unicode character matching. Existing case policy is applied before building the glob: insensitive matching uses the existing cached lowercase candidates and a lowercase query, including Unicode literals.

Regex, Exact and Glob switch each other off in the UI; the shared compiler rejects conflicting flags, including empty queries. The existing 256-character query cap bounds glob input, compilation occurs only on cache changes, and invalid syntax fails closed with an error. The same owner handles real members, navigation folders and exclusion. Size/type/folder/narrowing remain independent intersections. Saved snapshots include the mode in identity/labels, recall restores it, Reset clears it, and hidden selections remain intact. No payload reads, extraction or worker tasks are added.

Two regressions cover full-path separators vs filename scope, recursive zero/deep directory matching, alternatives/classes/escaping, case and Unicode literals, pinned byte-width wildcard behavior, syntax/conflicting-mode rejection, actual visible-row/cache changes, synthetic navigation, exclusion, hidden selection and saved/Reset state. Native mode selection, mask entry, recall, error/focus/layout remain pending: CUA is not exposed in this continuation and no native launch was attempted. Earlier archive captures do not qualify these controls or dependency/source changes.
