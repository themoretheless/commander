No upstream code copied. Commander retains its existing Unicode full-boundary `\b` semantics shared by page previews; this does not claim ripgrep's half-boundary edge behavior or complete regex dialect parity.

Search entire PDF now exposes Regex and Whole words alongside Match case. Each search snapshots every option; selecting a matching page initializes its find toolbar with that exact query/regex/case/word policy. Editing any global option retires the old report. Empty/whitespace-only pages are ignored, including for zero-width patterns, because they have no searchable displayed page text.
