# Zipped FictionBook text preview

Commander extension of the existing Strata-inspired ebook/archive preview work, closing the compressed-FB2 gap explicitly tracked in docs/strata-parity.md. No claim is made that current upstream Strata has identical ZIP member selection or limits; the implementation is independent and uses the already locked Rust zip/encoding/XML stack.

A filename ending .fb2.zip (case insensitive) now displays the single eligible FB2 member's book title/body/poetry/table text with the existing find/copy controls. Other .zip names retain existing behavior. A separate Zipped FB2 label identifies the representation. The captured outer-file snapshot, fingerprint/revision checks, cancellation, scheduling and cache remain owned by the existing text preview provider; no new path reread or archive extraction to disk occurs.

ZIP input is limited to 16 MiB and 4096 entries by the shared package opener. Selected member input and decoded XML remain bounded to 4 MiB, output to 256 KiB. Selection scans member indices: require exactly one non-directory .fb2 candidate, reject ambiguous books, symlink/directory mode candidates and empty/dot/parent/backslash/NUL path components. Unsupported/encrypted/malformed entries fail instead of silently choosing a different book. Both declared decompressed size and streamed output are bounded. ZIP integrity errors propagate; binary/book resources are not opened. Legacy Cyrillic/BOM encoding handling remains shared with raw FB2.

Regressions cover real deflated nested uppercase FB2 with irrelevant cover data, Windows-1251 text equality, malformed/no-book/multiple-book/unsafe names, cancellation, oversized decompression and corrupted member data. A filesystem-provider regression proves exact extracted text, ZIP input budget, cancellation and changed-source rejection. The member corruption fixture uses Stored compression so its payload can be modified deterministically; ordinary extraction and size tests use Deflate. Native application label/layout/find/copy interaction remains unqualified for the compressed variant.

The initial test run compiled the pre-correction integrity fixture while the fixture source was being corrected. That fixture wrongly searched for uncompressed FB2 bytes inside Deflate output and panicked before exercising extraction. Its logs are retained in initial-integrity-fixture. The final run uses a deterministic Stored member for payload corruption; Deflate extraction/size coverage remains separate. Production selection/decoding code was not weakened.

Final validation: all seven commands passed (audit, QA build, full tests, strict QA all-target Clippy, normal check, format, diff); 3302 passed / 3 ignored. Source/executable hashes retained. Optional external checksum helpers remain unavailable as documented in the preceding dependency-delivery bundle. Ambiguous ZIPs use the existing InvalidDocument diagnostic category, which is shared with malformed/encrypted/unsupported books; no dedicated multi-book picker/message is provided. Other archive wrappers and native compressed-book UI qualification remain open.
