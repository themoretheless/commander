# Custom navigation and held motion keys

Continuation of the [Kiorg configurable navigation/shortcut transfer](https://github.com/houqp/kiorg/blob/50aea44c9b4308b98f757574c527b7e0d3a344fe/crates/kiorg/src/config/shortcuts.rs), cohort #1. The F1 custom-shortcut command chooser now includes 16 basic actions that were absent from Commander's published command catalog: cursor up/down, first/last item, page up/down, their six selection-extension variants, pane switching, opening the highlighted entry, parent-folder navigation and toggle-selection-with-down. Existing left/right pane-focus commands remain available once, without duplicate choices. Saved navigation bindings use the same session representation as earlier command bindings.

Single-stroke cursor/selection motions now honor key-repeat events. Opening files, navigating parents, changing selection with a toggle, switching panes and other actions still execute once per physical press. Repeated leaders do not restart multistroke sequences, and holding a sequence's final key does not rerun the completed sequence. Existing exact modifiers, validation, input ownership, timeout/cancellation and command availability/operation guards remain shared.

The ordinary-key and custom-key paths now use the same execution method for Icons. Up/down move by the displayed column count, parent-row Down enters the first item, and selection-extension follows the same grid interval. List behavior is unchanged; counted Vim motions retain their existing semantics. Viewer/dialog/tool input remains outside custom workspace bindings.
