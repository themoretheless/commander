# Diff comparison options — 2026-10-31

Independent Rust/egui adaptation of the [Double Commander Compare by Contents options](https://doublecmd.github.io/doc/en/help.html#cm_CompareContents), cohort `doublecmd/doublecmd`. Its documented Ignore Blanks/Ignore Case controls are the interaction inspiration; no Pascal implementation was copied.

The Diff tool now offers **Ignore space changes** and **Ignore case**, both off by default. The first collapses each run of ASCII spaces/tabs into one space for comparison; missing spaces, leading/trailing presence, other Unicode whitespace and blank-line insertion/deletion remain distinct. The second compares Unicode lowercase character mappings, without locale-specific folding, full case folding (`ß`/`SS`) or Unicode normalization. Both compose, and changing either immediately recomputes the retained bounded text snapshot without rereading files. Reload reads the same captured operand paths and keeps the comparison policy.

Display text is never normalized: shared rows show the original `-` operand text, with an explicit caption while options are active. Normalized equality says “No differences under the selected comparison options”, rather than claiming the files are identical. CRLF/LF and final-newline identity remain exact; changed CRLF rows carry their visible marker whenever normalization is active, including mixed-ending files. No editor or merge mutation is introduced.

The existing 2 MiB per-file read cap and eight-million-cell LCS cap remain. The retained source pair costs at most another 4 MiB of text. Comparison keys are built once per line per recomputation, not per LCS cell; default comparison allocates no normalized-key vectors. Prefix/suffix pruning uses the selected equality. Changing policy rebuilds hunks, both operand line-number mappings, compact context, and find results; it clears stale jump/scroll/navigation state while preserving source-number visibility, compact/context choices and find query/options. Search operates on displayed original text, including `-` text on shared rows. Read errors clear retained source and derived results; Reload can recover. Matrix-limit errors retain the bounded source, allowing a normalization option to recover without rereading.

Five new regressions cover combined Unicode/blank comparison with original text and source coordinates, ignored-versus-significant whitespace/endings, normalized prefix/suffix pruning at the LCS limit, cached recomputation after both source files disappear with policy-preserving Reload recovery, and matrix-limit recovery. Native `diff_options` clicks each option on/off/on through six three-phase button sequences, checking counts at every transition and the final retained source, rows and hunk coordinates. It is included in the CI matrix and the stable scene registry.
