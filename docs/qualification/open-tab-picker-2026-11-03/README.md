# Searchable open folder tabs — 2026-11-03

Independent Rust adaptation of cohort #3 [Double Commander cm_ShowTabsList](https://doublecmd.github.io/doc/en/cmds.html). Cmd+Shift+A or the “Switch folder tab” command opens the omnibar's `#` mode. It searches custom tab names and full current paths across both panes, retaining duplicate paths as distinct numbered slots. Empty input retains pane/slot order and selects the focused tab. Results show pane, position, current/focused status, close protection and pin state; a pinned tab away from home also shows its return destination.

The picker takes a bounded header-only snapshot (at most sixteen entries), with no filesystem listing or inactive-tab activation. Name matches rank before path-only matches using the existing bounded Unicode fuzzy scorer. Queries longer than 128 characters show a clear error. Search/display text never becomes navigation identity: activation rechecks the captured native path, side, slot and global revision against the live workspace, then uses ordinary lazy tab activation and pinned-home behavior. Already-current tab choices focus the pane without reloading. Stale choices and blocked operations refuse with a reopen message. Editing input clears old tab rows and defers same-frame Enter until results are ranked for that exact input. Escape preserves panel/tab state.

Five new regressions cover grammar, shortcut/Select All separation, duplicate/title/path/Unicode ranking and query bounds, both-pane capture without loading, stale revision/path/modal refusal, same-tab no-reload and native path identity. The initial macOS fixture attempted to create a non-UTF-8 directory; APFS refused those bytes. The corrected regression tests native path preservation without requiring the host filesystem to admit the name. Initial failing logs are retained. A separate compile failure in the native driver was corrected before final checks.
