# Plain duplicate proposal path lists

Independent adaptation of [fclones one-path-per-line reports](https://github.com/pkolaczk/fclones/blob/main/fclones/README.md#features). Copy keeper paths exports only explicitly chosen keepers. Copy proposed Trash paths exports only the current proposed Trash members. Skipped groups, missing keeper choices and invalid keeper indices emit no paths. Lists use displayed group order and original member order and never read, remove or modify files.

Each selected path must be absolute, lossless UTF-8 and free of NUL/CR/LF. The entire output is refused if an included path is ambiguous or total output exceeds 1 MiB; no partial clipboard write occurs. Paths are plain text with trailing newlines, not shell commands or shell-quoted arguments. Spaces/Unicode are preserved. Empty plans yield an empty string. A bad path outside the requested action class does not prevent exporting valid selected paths. JSON/CSV remain available for structured reports; non-UTF-8 paths are not supported by this new format.

A regression checks both action classes and reverse group order, spaces, skipped/missing/invalid choices, invalid group order, relative/control paths, UTF-8 failure and output bounds. The existing duplicate_cross CI native scene now clicks both path-list buttons, retains the actual intercepted clipboard strings, then exports JSON again. Independent verification compares both strings exactly with per-file actions in that final proposal. Earlier folder preference clicks remain part of the same scene, and duplicate_roots is the neighboring control. QA uses owned temporary fixture storage and recording clipboard ports; this does not qualify the OS pasteboard or external consumers.

No dependencies changed; prior audit failures and the wider cohort transfer objective remain open. Native nested/unmatched preference scenarios, NUL-delimited export and fclones input compatibility are outside this milestone. Gate logs, source/binary identities, launch receipts, reports, clipboard lists and screenshots are retained here.

Final validation: all six gates passed, full suite 3283 passed / 3 ignored. Native path-list/folder-preference workflow and two-root control each passed 14/14, with five/one intercepted clipboard calls and all other effects zero. Independent verifier matched both actual clipboard lists byte-for-byte to final JSON actions and checked unchanged group/member identities, scan context, proposal totals, control count and source/binary identities. Both final frames were visually inspected; new buttons and result rows remain readable.
