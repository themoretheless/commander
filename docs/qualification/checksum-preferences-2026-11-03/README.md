# Remember checksum calculation choices — 2026-11-03

Independent continuation of cohort #96 [PeaZip's File Tools algorithm settings](https://peazip.github.io/verify-checksum-hash.html). Startup restores these choices before the first checksum request. Results, checksum input paths, expected digests, comparison encoding and relative-list state remain transient. Pending edits are saved even if they have not been applied to completed results.

The additive checksum_preferences value has its own version 1 and canonical algorithm labels, never enum ordinals or an untrusted raw bitmask. The array is bounded at fourteen entries; duplicates coalesce in stable algorithm order. Empty sets are deliberately preserved and remain disabled. Missing, malformed or future choices reset only checksum preferences to the existing defaults (All; SHA-256 selected; SHA-256 + XXH3-128 checked). The rest of the session still loads. Existing session envelope, schema, byte limits, generation gate and atomic writer remain shared.
