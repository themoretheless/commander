# Image metadata JSON snapshot export

Commander extension of the Strata-inspired image inspector: Get Info offers **Copy metadata JSON** once its matching metadata snapshot has loaded. The versioned `commander.image-metadata` report contains retained display properties, notes, source path, size, native object IDs and signed Unix nanosecond timestamp strings. It exports already displayed values, not raw typed EXIF or a fresh filesystem observation. No filesystem reread occurs on copy. Unix non-UTF-8 paths use exact byte hex; Unicode paths remain text. Output is capped at 64 KiB and errors never publish a partial report. Loading, failure and mismatched-owner states cannot copy.
