# UX redesign

Статус: принятое направление, до начала работы над UI. Этот документ —
модель взаимодействия; визуальный язык (сетка, цвет, типографика) будет
описан отдельно в `ui.md` поверх этой модели.

## 1. Диагноз

Ядро сильное, но интерфейс рос слоями: каждая функция принесла своё окно и
своё понятие.

| Проблема | Факт |
| --- | --- |
| Окна поверх панелей | 22 `egui::Window`: Search, Palette, Go to path, Recent, Sync, Diff, Duplicates, Treemap, Queue, History, Recovery, Safe state, Collections, Saved searches, Batch rename, Mask, Run command, Archive, Transfer, Confirm, Developer, Rename |
| Палитра как главный интерфейс | ~160 команд; без `Cmd+K` большинство функций не найти |
| Пять «наборов файлов» | selection, marks (`M`), stash + алгебра, drop-stack shelf, selection sets |
| Шесть навигаций | `Cmd+L`, `Cmd+P`, bookmarks `Cmd+1..9`, Favorites rail, дерево, history; плюс collections |
| Четыре сравнения | compare mode, diff, sync, duplicates (+ cross-pane select) |
| Инженерия в UI | Fast/Verified/Versioned, retention, safe-state lockout, BLAKE3, trust labels, rollout/kill switches |
| Конфликт клавиатур | vim-аккорды `j k g s` отбирают символы у type-ahead (оговорка в README) |

## 2. Принципы

**Цель — минимализм.** На экране по умолчанию только две панели и их пути.
Всё остальное появляется, когда нужно, и исчезает, когда не нужно. Каждый
новый элемент UI должен заменить хотя бы один старый.

1. **Две панели неприкосновенны.** Всё встраивается в панель или в край
   экрана. Плавающих окон нет; допустим только системный sheet для
   необратимых действий.
2. **Одно поле ввода** — omnibar — для пути, фильтра, поиска, команд, shell.
3. **Один набор файлов** — выделение, живущее между папками.
4. **Undo вместо подтверждения.** Спрашиваем только при конфликте имён или
   безвозвратном удалении.
5. **Надёжность по умолчанию и невидимо.** Журнал, верификация, резюм
   работают сами; пользователь видит результат и кнопку «Отменить».
6. **Всё, что можно сделать мышью, видно; всё, что видно, имеет клавишу.**

## 3. Решения по открытым вопросам

- **Целевой пользователь:** power user на macOS, пришедший из Total
  Commander / Far / Midnight Commander или упёршийся в Finder. Поэтому
  F-клавиши остаются основой, mac-хоткеи — стандартные.
- **Vim-аккорды** — опция в настройках, по умолчанию выключены. Тогда
  type-ahead работает без исключений.
- **Режем, а не только переупаковываем:** marks, stash-алгебра в UI, shelf,
  selection sets, профили операций в UI, developer panel в основном окне.
  Механика ядра (журнал, versioned store, BLAKE3) остаётся.

## 4. Модель

### 4.1 Экран

```
┌ Places ─┬─ ~/Projects/app ▾ ─────────────┬─ ~/Backup ▾ ─────────────────┐
│ ★ Home  │ ..                             │ ..                           │
│ ★ Proj  │ ▸ src            —   2 ч назад │ ▸ 2026-10        —  вчера    │
│ ★ Dl    │   Cargo.toml   1 KB  сегодня   │   app.zip     12 MB  вчера   │
│ Collect.│ ● README.md   20 KB  сегодня   │                              │
│ Volumes │                                │                              │
│         ├─ 34 items · 1.2 GB  [3 sel ✕] ─┼─ 2 items · 12 MB ────────────┤
├─────────┴────────────────────────────────┴──────────────────────────────┤
│ ⟳ Copy 3 → ~/Backup  ▓▓▓▓▓░░ 64% · 12 s        ✓ Moved 12 files · Undo   │
│ F3 View  F5 Copy  F6 Move  F7 New  F8 Trash   ⌘K Command  ⌘= Compare     │
└─────────────────────────────────────────────────────────────────────────┘
```

Так экран выглядит со всеми зонами. **По умолчанию видны только две
панели с omnibar и подвалом.** Places скрыта (`Cmd+0`), Activity появляется
только пока идёт операция или висит Undo, key bar скрыт и всплывает при
удержании `Shift`/`Cmd`/`Fn` (опция «всегда показывать» — в настройках).
Тулбара нет. Колонки — имя, размер, дата; остальное — в tooltip и Get Info.
Декора нет: без рамок вокруг панелей, без иконок в кнопках, без цветов
кроме акцента активной панели, выделения и состояний Compare.

### 4.2 Omnibar

Строка пути каждой панели — поле ввода (клик, `Cmd+L`, или просто начать
печатать). Префикс задаёт режим:

| Ввод | Режим | Результат | Заменяет |
| --- | --- | --- | --- |
| `abc` | фильтр | панель фильтруется на лету; ниже — совпадения из recent/pinned; `Enter` — открыть курсор, `Esc` — сброс | filter box, type-ahead, Recent (`Cmd+P`) |
| `/…` `~…` | путь | автодополнение по сегментам, `Tab` дополняет | Go to path |
| `?abc` | поиск | рекурсивный поиск от текущей папки, результаты — виртуальная папка в этой же панели | Search, Saved searches |
| `>abc` | команда | fuzzy-список команд с причиной недоступности | Command palette |
| `!cmd` | shell | запуск в текущей папке, вывод — в Activity | Run command |

- Синтаксис поиска (поля, regex, content) — тот же, что сейчас; подсказки
  появляются по мере ввода, а не в отдельной форме.
- История omnibar общая и учитывает режим; «сохранённый поиск» = закреплённая
  запись истории (★), появляется в Places.
- `Cmd+K` = фокус omnibar с префиксом `>`, `Cmd+F` — с `?`, `Cmd+P` — пустой
  (фильтр + recent).
- Facets фильтра (kind / size / date) — чипы под omnibar, видны только в
  режимах фильтра и поиска.

### 4.3 Выделение (одно)

- `Space`/`Insert` — переключить, `Shift+стрелки` — диапазон, `Cmd+A`,
  `Cmd+Shift+I`, клик/`Cmd+клик` мышью.
- **Выделение не сбрасывается при переходе в другую папку.** В подвале
  панели — чип «12 файлов в 3 папках ✕»; клик раскрывает список (можно
  убрать отдельные пункты), `✕` / `Esc` дважды — сброс.
- F5/F6/F8 и все команды работают с выделением целиком, откуда бы оно ни
  было собрано. Это закрывает сценарии shelf, gather и marks.
- Если выделения нет — действие применяется к файлу под курсором.
- Select by mask → `>select *.jpg` или фильтр + `Cmd+A`.
- Алгебра (union/subtract/…) и cross-pane select («только здесь»,
  «отличающиеся», «одинаковые») — команды `>`, без отдельных наборов.

Удаляется: marks, stash, drop-stack shelf, selection sets как UI-понятия.

### 4.4 Операции и Activity

**Запуск.** F5/F6 стартуют сразу, без окна подтверждения. Цель —
противоположная панель. Сменить цель можно `Shift+F5` / `Shift+F6`: omnibar
активной панели в режиме пути с подставленной целью (и для переименования
одного файла — его имя).

**Activity** — полоса над key bar, единое место для очереди, прогресса,
истории, восстановления и undo:

- Идёт операция — одна строка: что, куда, %, ETA. Несколько — счётчик
  «+2 в очереди». Клик / `Cmd+J` разворачивает ленту.
- Развёрнутая лента: активная, ожидающие (пауза, порядок, отмена), затем
  завершённые за сессию с «Undo» и «Показать».
- **Конфликт** не блокирует всю операцию до старта: копирование идёт, а
  конфликтующие файлы собираются в строку операции «3 конфликта —
  Заменить / Оставить оба / Пропустить / По одному». Политика по умолчанию
  без ответа — пауза на этих файлах, остальное копируется.
- Нехватка места, read-only том, копирование в себя — ошибка показывается
  до старта, inline в той же полосе, с причиной.
- Завершение — «✓ Скопировано 12 файлов · Undo», исчезает через 8 с или по
  следующему действию; остаётся в развёрнутой ленте.
- Прерванная операция (краш, отключение диска) при запуске показывается в
  ленте как «Прервано · Продолжить / Откатить / Подробнее». Это и есть
  Recovery center; отдельного окна и экрана safe-state нет — safe-state
  блокирует только затронутые операции и пишет это в их строку.
- Удаление (F8) — в корзину, без вопроса, с Undo. `Shift+F8` — безвозвратно,
  единственный случай системного sheet-подтверждения.

**Профили** Fast/Verified/Versioned и retention уходят в Settings →
Operations. По умолчанию **Auto**: clone/rename где возможно, verify на
внешних/сетевых томах, versioned — выключен.

### 4.5 Режимы панели

Переключатель в правой части omnibar, клавиши `Cmd+1..4` заняты Places,
поэтому `Ctrl+1..4`:

| Режим | Что | Заменяет |
| --- | --- | --- |
| List | текущий список | — |
| Preview | превью файла под курсором **другой** панели (как F3 сейчас) | Preview toggle |
| Disk usage | treemap/столбцы размеров текущей папки; в нём работают навигация, выделение и F8 | окно Treemap |

Архивы — обычная навигация: `Enter` на `.zip/.tar.gz` открывает его как
папку (бейдж «архив, только чтение» в omnibar). F5 из архива = извлечь.
Окно Archive удаляется.

### 4.6 Compare

`Cmd+=` включает режим сравнения сразу для обеих панелей:

- строки подсвечены цветом + значком: только здесь / новее / старше /
  отличается / одинаковый / конфликт тип-тип;
- в подвале — сводка и действия: «Выделить отличающиеся», «Синхронизировать
  → », «← Синхронизировать», «В обе стороны»; синхронизация показывает план
  inline в панелях (зачёркнутое / добавляемое) и запускается `Enter`
  как обычная операция Activity;
- `Enter` на паре текстовых файлов — inline diff, занимающий обе панели;
  `Esc` — назад;
- `>duplicates` — поиск дубликатов, результат — виртуальная папка с
  группами (как результаты поиска).

Удаляются окна Diff, Synchronize, Duplicates.

### 4.7 Places

Левая колонка, `Cmd+0` — показать/скрыть:

1. **Pinned** — упорядоченный список; первые 9 — это `Cmd+1..9`. Закрепить:
   `Cmd+Shift+1..9` или перетащить. Bookmarks и Favorites rail сливаются.
2. **Searches** — закреплённые запросы omnibar.
3. **Collections** — виртуальные корни (как сейчас), создаются из
   выделения: `>new collection`.
4. **Volumes** — тома и их свободное место.
5. **Tree** — дерево текущей панели, свёрнуто по умолчанию.

Recent — в omnibar. History `Cmd+[` / `Cmd+]` остаётся как есть.

### 4.8 Переименование

- `F2` / `Enter` на имени — inline-редактирование в строке, без окна.
  Имя выделено без расширения.
- Несколько файлов + `F2` — batch rename **inline**: правая панель
  становится превью «было → станет», omnibar активной панели — поле шаблона
  (regex/счётчик/дата — подсказки при вводе). `Enter` — применить, `Esc` —
  отмена.

### 4.9 Клавиатура

Основа — Commander + mac:

| Клавиша | Действие |
| --- | --- |
| `Tab` | другая панель |
| `Enter` / `Backspace` | войти / вверх |
| `Space` / `Insert` | выделить |
| `F2` | переименовать (inline) |
| `F3` | Preview в другой панели |
| `F4` | открыть во внешнем редакторе |
| `F5` / `F6` | копировать / переместить в другую панель |
| `Shift+F5` / `Shift+F6` | то же, с выбором цели |
| `F7` | новая папка (inline-строка) |
| `F8` / `Shift+F8` | в корзину / безвозвратно |
| `Cmd+K` `Cmd+F` `Cmd+L` `Cmd+P` | omnibar: команда / поиск / путь / фильтр |
| `Cmd+=` | Compare |
| `Cmd+J` | развернуть Activity |
| `Cmd+0` | Places |
| `Cmd+1..9` | pinned |
| `Cmd+Z` / `Cmd+Shift+Z` | undo / redo |
| `Cmd+E` / `Cmd+U` | выровнять / поменять панели |
| `Cmd+.` | показать скрытые |

Key bar внизу генерируется из контекста (уже так), с модификаторами —
при зажатом `Shift`/`Cmd` показывает соответствующий слой.

Vim-аккорды — опция; при включении type-ahead переезжает на `/`.

### 4.10 Пустые состояния и ошибки

Оставляем текущую хорошую идею (пусто / отфильтровано / нет доступа с одним
действием восстановления) и распространяем её на всё: любая ошибка
показывается **там, где возникла** (в строке файла, в подвале панели, в
строке операции), с одной кнопкой исправления. Тостов-ошибок без контекста
нет.

### 4.11 Что уходит из основного UI

- Developer diagnostics, rollout/kill controls, capability report, support
  bundle → меню Help → Diagnostics (одна страница настроек).
- Trust labels, provenance → только tooltip / «Подробнее» в строке
  операции.
- Density, text size, theme → Settings → Appearance (+ `Cmd+±` для размера).

## 5. Сценарии: было → стало

| Задача | Было | Стало |
| --- | --- | --- |
| Скопировать в соседнюю панель | F5 → окно подтверждения → окно прогресса | F5 → полоса Activity → Undo |
| Найти файл | `Cmd+F` → окно → результаты в окне | `?name` → результаты в панели, F5 работает сразу |
| Собрать файлы из трёх папок | shelf `Cmd+Shift+A`… `Cmd+Shift+V` | выделить в трёх папках → F5 |
| Синхронизировать две папки | `Cmd+Shift+S` → окно | `Cmd+=` → «Синхронизировать →» → `Enter` |
| Что занимает место | treemap в окне | `Ctrl+3` в панели, удалять прямо там |
| Переименовать 40 фото | окно Batch rename | выделить → `F2` → шаблон, превью справа |
| Восстановиться после сбоя | Recovery center / Safe state | строка «Прервано · Продолжить» в Activity |
| Перейти в папку | 6 способов | omnibar (печатать) или `Cmd+1..9` |

## 6. Итог по окнам

22 → 0 плавающих окон. Остаются: системный sheet для `Shift+F8`, Settings
(отдельное окно приложения, как принято в macOS), системное контекстное
меню.

## 7. План внедрения

Каждый шаг — отдельный PR, приложение рабочее после каждого.

1. **Activity** — объединить transfer/queue/history/recovery/safe-state;
   F5/F6 без подтверждения, конфликты inline. Самый большой выигрыш.
2. **Omnibar** — путь + фильтр + recent, затем `?` поиск в панели, `>`
   команды, `!` shell. Удалить соответствующие окна.
3. **Выделение между папками** — удалить marks, shelf, stash-UI.
4. **Inline rename / batch rename / новая папка.**
5. **Режимы панели и Compare** — удалить Treemap, Diff, Sync, Duplicates,
   Archive окна.
6. **Places** — слить bookmarks/favorites/tree/collections/saved searches.
7. **Settings и Diagnostics** — вынести профили, внешний вид, developer.
8. **UI-проход** (`ui.md`): сетка, плотность, цвет, типографика.

## 8. Риски

- Потеря discoverability при удалении окон — компенсируется `>` и key bar
  со слоями модификаторов.
- Выделение между папками может удивить («почему скопировалось 12, а не
  3?») — чип в подвале всегда виден, а Activity показывает точное число до
  и после.
- F5 без подтверждения — страхуется Undo, preflight (место, read-only,
  в себя) и тем, что конфликты не перезаписываются без ответа.
